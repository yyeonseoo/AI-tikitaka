# RAPID: 로봇 결정 합성 데이터로 실험 조건 예측하기

이전 PCE 연구([../pce/](../pce/README.md))와 따로 진행한 연구입니다. 여기에는 최종 결과만 적었습니다. 단계별 계획과 결과 원문은 [LOG.md](LOG.md)에 있습니다.

## 데이터

미국 로런스 버클리 국립연구소의 로봇이 페로브스카이트 단결정을 합성한 실험 9,483건입니다 (Pendleton et al., *J. Phys. Chem. C* 2020, [github.com/ipendlet/MLScripts](https://github.com/ipendlet/MLScripts), CC-BY 4.0).

실험 한 건은 이렇습니다. 용매(대부분 GBL)에 PbI₂(요오드화납)와 아민(유기 분자, 45종 중 하나)을 녹이고 포름산을 넣은 뒤 가열합니다. 온도(대부분 95°C), 시간(대부분 3.5시간), 교반 속도는 거의 고정이고, 실험마다 바꾼 건 주로 PbI₂·아민·포름산 세 가지의 농도입니다. 아민 하나당 보통 96건(96칸 판 한 장)을 실험했습니다.

결과는 연구팀이 눈으로 매긴 1~4점입니다. 1은 고체 없음, 2는 가루, 3은 작은 결정, 4는 0.1 mm가 넘는 큰 결정입니다. 결정 구조를 분석하려면 4점이 필요합니다. 전체의 약 20%가 4점이고, 45종 중 14종은 4점이 한 번도 나오지 않았습니다.

분석에서는 PbI₂나 아민이 0인 실험과 용매 기록이 없는 실험을 빼고 9,258건을 썼습니다.

받는 법: `git clone --depth 1 https://github.com/ipendlet/MLScripts.git rapid/data/MLScripts` (`rapid/data/`는 git에 올리지 않음)

## 무엇을 알고 싶었나

처음 써 보는 아민으로 실험할 때, 어떤 농도로 하면 큰 결정(4점)이 나오는지 머신러닝으로 미리 알려줄 수 있는지.

## 어떻게 했나

- 모델은 주로 LightGBM(결정 트리를 여러 개 합친 모델)을 썼고, 비교용으로 로지스틱 회귀(선형 모델)와 머신러닝이 없는 단순 규칙을 함께 돌렸습니다.
- "처음 보는 아민"을 흉내 내려고 아민 단위로 데이터를 나눴습니다. 아민 45종을 다섯 묶음으로 나눠 한 묶음은 시험용으로 빼고, 나머지를 학습용과 검증용(설정 고르기)으로 다시 나눴습니다. 시험용 아민의 실험은 학습에 전혀 들어가지 않습니다.
- 성능은 주로 AUC로 쟀습니다. 4점인 실험과 아닌 실험을 하나씩 뽑았을 때 모델이 4점 쪽을 더 높게 볼 확률이고, 0.5면 찍기와 같고 1이면 완벽합니다.
- 실행하기 전에 판정 기준을 정해서 커밋했고, 결과가 나온 뒤 기준을 바꾸지 않았습니다.

## 결과

| 질문 | 결과 | 단순한 방법과 비교 |
|---|---|---|
| 처음 보는 아민에서, 실험하기 전에 4점을 맞힐 수 있나 | 못 맞힘. AUC 0.62, MCC 0.02 (원 논문도 같은 결론) | – |
| 처음 보는 아민으로 8번 실험해 본 뒤 나머지를 맞힐 수 있나 | AUC 0.72. 추천 상위 20% 중 43%가 4점 (그냥 고르면 23%) | 8번 중 4점이 있으면 "4점 나온 조건과 농도가 가까운 순서로 고르기"와 같음 (0.77 대 0.77). 8번이 다 실패면 실험 전과 같은 수준 |
| 처음 보는 아민에서 첫 4점을 빨리 찾을 수 있나 | 머신러닝 전략 6가지 모두 무작위보다 빠르지 않음 (무작위 7.6번, 나머지 8.3~10.8번) | 무작위가 가장 빠름 |
| 처음 보는 아민에서 "아무것도 안 생길 조건"(1점)을 맞힐 수 있나 | 잘 맞힘. AUC 0.88 | 농도 3개만 쓴 로지스틱 회귀가 0.87, 포름산 농도 하나로 줄 세워도 0.80 |
| 이미 실험한 아민에서 좋은 조건을 추천할 수 있나 | 잘 됨. AUC 0.88, 추천 상위 20% 중 60%가 4점, 첫 4점까지 2.1번 (무작위 5.3번) | 같음. 같은 아민의 학습 실험에서 4점 조건과 가까운 순서로 고르기가 AUC 0.87 (차이 +0.01, 95% 구간 −0.03~+0.05), 가까운 실험 5개의 4점 비율이 0.84 |
| 실험 전에 4점이 가능한 아민인지 알 수 있나 | 약함. 아민 크기 하나로 AUC 0.69, 분자 특성을 다 넣으면 0.43 | 크기 하나가 가장 나음 |

그 밖에 확인한 것:
- 같은 아민, 같은 조건으로 다시 실험했을 때 4점이 다시 나올 확률은 0.90입니다. 실험 자체는 잘 재현됩니다.
- 결과에 가장 크게 영향을 주는 건 포름산 농도, PbI₂ 농도, 아민/PbI₂ 비율 순입니다. 포름산을 넣지 않은 실험 140건에서는 4점이 한 번도 없었고, 아민/PbI₂ 비율이 1~2 근처일 때 결과가 좋았습니다.
- 처음 보는 아민으로 실험을 늘리면 약 16~24번에서 32번 했을 때의 성능에 거의 도달합니다.

## 결론

- 처음 보는 아민에 대해 머신러닝이 단순한 방법보다 낫다는 결과는 나오지 않았습니다.
- 성능이 잘 나온 과제("아무것도 안 생길 조건" 맞히기, 이미 실험한 아민의 추천)도 선형 모델이나 "성공한 조건 근처 고르기"로 같은 성능이 나왔습니다. 결과가 주로 농도의 단순한 경향으로 정해지기 때문입니다.
- 처음 보는 아민을 못 맞히는 이유는 실험이 불안정해서가 아니라 아민마다 성질이 달라서입니다. 아민이 45종뿐이라 아민의 특성으로 이 차이를 배우기 어렵습니다.
- 선행연구(원 논문, PLATIPUS 2022)는 이런 단순한 방법과 비교하지 않았습니다. 이 연구에서 남는 건 "비교해 보면 머신러닝의 이점이 사라진다"는 확인입니다.

## 한계

- 모든 평가는 연구팀이 이미 실험한 조건 안에서 흉내 낸 것입니다. 해 보지 않은 농도 조합은 평가할 수 없고, 연구팀이 처음부터 될 법한 곳 위주로 실험했기 때문에 "그 안에서 무작위로 고르기"가 유리했을 수 있습니다.
- 온도, 시간, 장비 같은 조건이 고정된 한 로봇의 데이터라, 다른 실험실에서도 같은 결과가 나올지는 알 수 없습니다.
- PLATIPUS(2022)의 방법은 직접 돌려서 비교하지 않았습니다.
