# RAPID: 새 아민에서 결정이 생길지 예측

이전 PCE 연구([../pce/](../pce/README.md))와 별개인 연구입니다. 파일은 이 README(질문·계획·결과 요약), 단계별 스크립트 `stepN.py`, 그 결과 `results_stepN.md`뿐입니다.

## 데이터

- 로봇이 할라이드 페로브스카이트 단결정을 합성한 실험 9,483건, 유기 아민 45종 (역온도 결정화. Pendleton et al., *J. Phys. Chem. C* 2020; [github.com/ipendlet/MLScripts](https://github.com/ipendlet/MLScripts), CC-BY 4.0)
- 입력: PbI₂·아민·포름산 농도, 반응 온도·시간, 교반 속도, 혼합 시간, 아민 분자 물성 67개
- 출력: 결정 점수 1~4 (4 = 0.1 mm 넘는 큰 결정). 점수 0(미기록) 49건 제외 → 9,434건, 4점 비율 19.6%

## 2단계 계획: 새 아민에서 적은 실험으로 결정 조건 찾기 (실행 전 확정, 2026-10-08)

실행 후 방법·지표·기준을 바꾸면 그 사실과 이유를 결과에 따로 적습니다.

### 질문

실제 화학자는 새 아민을 받으면 실험을 몇 번 해 봅니다.

> **새 아민으로 실험을 몇 번(k번)만 해 보면 남은 조건들의 결과를 얼마나 잘 예측하나? 다른 아민 44종에서 배운 지식이 그 몇 번을 얼마나 보완하나?**

| 질문 | 내용 |
|---|---|
| Q1 (k = 0) | 실험 없이 아민 분자 물성만으로 "결정을 잘 만드는 아민인가"를 맞힐 수 있나 |
| Q2 (k = 0) | 아민 안 조건 순위를 매길 수 있나. 화학 입력(몰비)이 도움이 되나 |
| **Q3 (주, k = 4·8·16·32)** | 다른 아민 모델을 새 아민의 k번 결과로 보정하면, 보정 없이 쓰거나 새 아민 데이터만 쓰는 것보다 나은가 |
| Q4 (참고) | k번을 모델이 불확실한 조건부터 고르면 무작위로 고르는 것보다 나은가 |

### 입력

| 묶음 | 내용 |
|---|---|
| 반응 조건 | PbI₂·아민·포름산 농도, 온도, 반응 시간, 교반 속도, 혼합 시간 (8개) |
| 화학 입력 (추가) | 아민/PbI₂ 몰비, 포름산/PbI₂ 몰비 |
| 아민 물성 | 분자 물성 67개 |

### 방법

| 방법 | 설명 |
|---|---|
| 보정 없음 | 다른 아민 44종으로 학습한 LightGBM을 그대로 적용 (1단계 기준선) |
| 새 아민 k번만 | 새 아민의 k번 결과로만 학습 (로지스틱 회귀) |
| **보정 (주 방법)** | 위 LightGBM의 예측을 새 아민의 k번 결과로 보정. 그 아민의 성공 수준(절편)과 민감도(기울기)만 다시 맞추고, 조건 간 순서는 LightGBM 것을 씀 |
| 추가 학습 | k번 결과를 가중치를 줘서 학습 데이터에 넣고 LightGBM을 다시 학습 |
| 아민 성공 비율 모델 (Q1) | 아민 물성 → 아민별 4점 비율 (학습 아민 44개) |
| 무작위 | MCC 0, AUC 0.5 |

k번을 고르는 방법: 무작위(주), 모델 불확실성 기준(Q4).

### 평가와 판정

- **방식:** 아민 하나 빼기. 빼낸 아민의 실험 중 k번을 공개하고 나머지 실험으로 채점합니다. k번 무작위 추출은 아민마다 20번 반복해 평균합니다.
- **주 지표:** 빼낸 아민별 MCC의 평균 (원 논문과 같은 지표)
- **보조 지표:** 아민별 AUC 평균, Brier 점수(확률이 맞는 정도), 아민 성공 비율 예측의 순위 상관(Q1)
- **불확실성:** 아민 단위 부트스트랩 1,000회. 방법끼리는 같은 재표집에서 짝지어 비교합니다. 95% 구간이 0을 포함하면 "우열을 판단할 증거 부족"으로 씁니다.
- 4점이 없거나 전부 4점인 아민은 AUC에서 빠집니다(31종 남음). 원 연구팀 모델이 고른 실험(`_raw_model_predicted`)의 비율도 보고합니다.

| 판정 | 기준 |
|---|---|
| **주 성공** | k = 8에서 (보정 − 보정 없음)과 (보정 − 새 아민 k번만)의 아민별 MCC 차이 95% 구간 하한이 둘 다 0보다 큼 |
| 보조 1 | k = 0에서 화학 입력 추가가 아민 안 AUC를 올리는가 |
| 보조 2 | 아민 물성으로 아민별 성공 비율을 무작위보다 잘 맞히는가 (순위 상관 하한 > 0) |
| 참고 | k = 4·16·32 곡선, 불확실성 기준 vs 무작위 선택 |

**일정:** 코드 1~2일, 실행 수십 분 이내, 정리 1~2일. **하지 않는 것:** 뉴로심볼릭 모델.

## 2단계 결과 (2026-10-08)

전체 표: [results_step2.md](results_step2.md). 실행 중 수정: k번 학습 로지스틱 회귀에서 PbI₂ = 0인 실험(131건)의 빈 몰비를 중앙값으로 채움(코드 오류 수정, 계획 변경 아님).

**주 판정: 미달.** k = 8에서 보정 − 보정 없음 +0.012 [−0.008, +0.034] (우열 판단 증거 부족), 보정 − 새 아민 k번만 −0.066 [−0.108, −0.029] (뒤가 높음). 확률 수준만 맞추고 조건 순서는 그대로 두는 보정으로는 처음 보는 아민의 틀린 순서를 고치지 못했습니다.

| 방법 (아민별 평균) | k = 8 MCC | k = 8 AUC | k = 32 MCC | k = 32 AUC |
|---|---|---|---|---|
| 보정 없음 | 0.02 | 0.64 | 0.02 | 0.64 |
| 새 아민 k번만 | 0.10 | 0.65 | 0.15 | 0.78 |
| 보정 (계획한 주 방법) | 0.03 | 0.62 | 0.04 | 0.63 |
| **추가 학습** (k번을 가중치 10으로 학습 데이터에 넣고 다시 학습) | **0.15** | **0.73** | **0.25** | **0.82** |

- **사후 분석 (계획에 없던 비교, 판정에 쓰지 않음):** 추가 학습은 k = 4·8·16·32 모두에서 새 아민 k번만, 보정 없음보다 MCC와 AUC가 높았습니다(16개 비교 모두 구간 하한 > 0). 예: k = 8에서 추가 학습 − 새 아민 k번만 MCC +0.050 [+0.024, +0.079], AUC +0.074 [+0.040, +0.107]. 다른 아민 지식과 새 아민의 적은 실험을 합치는 것이 각각보다 낫다는 신호이지만, 확인하려면 새 계획으로 다시 검증해야 합니다.
- **Q1:** 아민 물성 67개 → 아민 성공률 순위 상관 0.34 [0.04, 0.59]. 무작위보다 낫지만, 아민 부피 하나와 성공률의 상관(−0.51, 학습 없음)보다 약합니다.
- **Q2:** 몰비 추가의 AUC 효과 −0.019 [−0.043, +0.003], 우열 판단 증거 부족.
- **Q4:** 불확실한 조건부터 고르는 것은 무작위 선택보다 나은 증거가 없습니다.
- **한계:** RAPID 데이터 EDA 없이 원 논문 입력을 그대로 썼습니다. 공정 변수 대부분이 거의 고정(95°C 77%, 3.5시간 91%, 750 rpm 92%)이고, 아민 물성 67개는 아민 45종의 이름표 역할을 할 수 있습니다. 결론은 EDA 후 입력을 정리하고 다시 확인합니다. 원 연구팀 모델이 고른 실험이 20.5%입니다.

## 3단계 계획: "큰 결정을 원해 + 이 용매를 쓸 거야" → 농도 조건 추천 (2026-10-08)

2단계의 PLATIPUS(2022) 비교를 확인해 보니, "과거 데이터 + 새 아민 k번으로 재학습"은 이미 그 연구의 비교 방법에 있었습니다. 그래서 연구 질문을 **조건 추천**으로 옮깁니다.

### 질문

> 아민과 용매를 정하고 "큰 결정(4점)"을 원할 때, 어떤 농도 조합부터 실험하라고 추천할 수 있는가? 추천 상위 조건이 실제로 무작위보다 성공률이 높은가?

### 범위 (데이터 확인 결과로 정함)

- **용매:** GBL(아민 29종, 성공 있는 아민 20종), DMF(10종, 9종) 중심. DMSO(7종 중 성공 3종)는 결과를 따로 표시하고, GBL+DMF(1종)와 용매 미기록(22건)은 뺍니다. 아민마다 거의 한 용매로만 실험해서, **용매를 바꾸는 효과는 추정하지 않습니다.**
- **추천하는 조건:** PbI₂·아민·포름산 농도 3개. 온도·반응 시간·교반 속도는 대부분 고정값(95°C, 3.5시간, 750 rpm)이라 추천하지 않고 고정값으로 안내합니다.
- **추천 범위:** 그 용매에서 실제로 실험해 본 농도 범위 안으로만 제한합니다.

### 상황별 추천

| 상황 | 방식 |
|---|---|
| 이미 실험된 아민 | 그 용매 데이터로 학습한 모델로 성공 확률이 높은 농도 순 추천 |
| 처음 보는 아민 | 먼저 해 볼 조건 k개 추천 → 결과로 재학습 → 나머지 추천 (k = 0·8·16·32) |

### 차별점 (선행연구 대비)

원 논문(2020)은 실험 0번에서의 분류, PLATIPUS(2022)는 실험 10번 + 액티브러닝에서의 분류를 다뤘습니다. 이 연구는 다음 세 가지를 더합니다.

| # | 내용 | 비고 |
|---|---|---|
| ① | **추천기로서의 평가:** 추천 상위 10개 중 실제 4점 비율, 첫 4점까지 필요한 실험 수 | 선행연구는 분류 지표(MCC, BCR)만 보고 |
| ② | **멈출 시점:** 새 아민에서 실험 k번 후 예측이 충분히 안정됐는지 판단하는 규칙. 아민별로 필요한 실험 수를 예측 | 같은 연구팀이 미해결 문제로 언급(Li et al., *Chem. Mater.* 2022) |
| ③ | **실험 0번 출발점:** 결정 형성과 직접 관련된 아민 기하 변수(유효 반지름, 최소 단면적, 암모늄기 수, 유연성 등)로 "잘 되는 아민"을 예측. 기존 물성 67개와 비교 | 성공하면 가장 강한 차별점, 실패 위험도 가장 큼. 외부 결정 구조 DB 활용은 데이터 확보 가능성 확인 후 결정 |

### 평가

- 데이터에 있는(실제로 실험한) 조건만 채점할 수 있습니다. 아무도 안 해 본 농도 조합의 추천은 실험 없이 검증할 수 없습니다.
- **주 지표:** 추천 상위 10개 조건 중 실제 4점 비율, 그 아민의 무작위 기대값(아민별 4점 비율)과의 차이
- **보조 지표:** 아민 안 AUC, 첫 4점이 나올 때까지 필요한 실험 수
- **평가 방식:** 이미 실험된 아민은 아민 안 무작위 분할(조건 단위), 처음 보는 아민은 아민 하나 빼기. 불확실성은 아민 단위 부트스트랩
- 판정 기준은 EDA 후, 실행 전에 이 절에 확정해서 적습니다.

### EDA (이 계획 기준, 실행 전)

1. 용매별·아민별로 농도 3개가 덮는 범위, 4점이 몰리는 농도 영역
2. 온도·시간·교반이 정말 고정인지, 바뀐 실험에서 성공률 차이가 있는지
3. PbI₂ = 0 같은 이상한 실험 (131건), 점수 0, 용매 미기록 실험
4. 아민 물성 67개 중복 정리 → 적은 수의 의미 있는 물성으로 줄일 수 있는지. ③용 기하 변수(유효 반지름, 최소 단면적, 암모늄기 수, 회전 결합 수)와 아민별 성공률의 관계 (아민 45개라 탐색용)
5. 원 연구팀 모델이 고른 실험(20.5%)과 무작위 실험의 성공률 차이 (추천 평가가 부풀려질 수 있음)
