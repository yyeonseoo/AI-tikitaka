# RAPID: 로봇 결정 합성 데이터로 실험 조건 고르기

이전 PCE 연구([../pce/](../pce/README.md))와 별개인 연구입니다. 이 파일은 요약이고, 단계별 계획(실행 전 커밋)과 결과 원문은 [LOG.md](LOG.md)에 있습니다.

## 데이터

- 로봇이 할라이드 페로브스카이트 단결정을 합성한 실험 9,483건, 유기 아민 45종 (Pendleton et al., *J. Phys. Chem. C* 2020; [github.com/ipendlet/MLScripts](https://github.com/ipendlet/MLScripts), CC-BY 4.0)
- 실험 한 건: 용매에 PbI₂(요오드화납)와 아민을 녹이고 포름산을 넣어 가열(대부분 95°C, 3.5시간). 아민 하나당 보통 96건이고, 주로 세 농도(PbI₂·아민·포름산)를 바꾼 서로 다른 조합입니다.
- 결과: 결정 점수 1~4 (1 = 고체 없음, 2 = 가루, 3 = 작은 결정, 4 = 0.1 mm 넘는 큰 결정). 이 연구팀이 정한 점수입니다.
- 분석 대상: PbI₂ = 0, 아민 = 0, 용매 미기록 실험을 뺀 9,258건, 4점 비율 약 20%
- 받기: `git clone --depth 1 https://github.com/ipendlet/MLScripts.git rapid/data/MLScripts` (`rapid/data/`는 git 제외)

## 지금까지의 결론 (1부: 처음 보는 아민에서 조건 예측·추천)

| 질문 | 결과 |
|---|---|
| 처음 보는 아민의 4점 여부를 실험 없이 맞힐 수 있나 | **못 함.** MCC 0.02~0.04 (0 = 무작위), 원 논문 0.15 |
| 이미 실험한 아민에서 조건 추천 | 잘 됨. 추천 상위 20% 중 60%가 4점 (기본 24%), 첫 4점까지 2.1번 (무작위 5.3번) |
| 처음 보는 아민 + 8번 실험 후 재학습 | 상위 20% 중 43%가 4점 (기본 23%). **하지만 8번 중 4점이 있으면 "4점 근처 조건 고르기" 단순 규칙과 성능이 같고(AUC 0.77 vs 0.77), 8번이 모두 실패면 실험 0번 수준(0.62)** |
| 몇 번 실험하면 충분한가 | 약 18번이면 32번 성능에 근접 (경계에서 기준 충족) |
| 실험 재현성 | 같은 조건 반복 시 4점 재현 0.90 → 한계는 실험 잡음이 아니라 아민 간 차이 |
| 무엇이 결과를 좌우하나 (SHAP) | 포름산 농도 > PbI₂ 농도 > 아민/PbI₂ 몰비 ≈ 아민 농도 |

**요약:** 첫 4점을 찾은 뒤에는 그 근처를 고르면 되고, 머신러닝이 그 이상을 하지 못했습니다. **진짜 어려운 문제는 처음 보는 아민에서 첫 4점을 찾는 것**이고, 2부는 이 문제를 다룹니다. (PLATIPUS 비교로 계획했던 4-3은 2부 결과를 본 뒤 필요하면 진행합니다.)

## 2부 계획: 처음 보는 아민에서 첫 4점을 가장 빨리 찾기 (2026-10-09, 실행 전 확정)

### 근거 (계획 전 확인)

같은 아민 안에서, 각 실험과 농도가 가장 가까운 실험 5개 중 4점의 비율 (아민 31종 평균, 그 아민 기본 비율 약 0.23):

| 이 실험의 점수 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 가까운 실험 중 4점 비율 | 0.10 | 0.16 | **0.27** | **0.54** |

1점 근처에는 4점이 적고, 3점 근처에는 많습니다. 기존 연구(원 논문, PLATIPUS)는 4점 여부만 썼는데, **2·3점과 1점도 "어디로 가야 하나"의 정보**가 됩니다.

### 질문

> 처음 보는 아민으로 실험을 하나씩 할 때, 어떤 순서로 하면 첫 4점이 가장 빨리 나오나? 1~3점 결과를 버리지 않고 쓰면 더 빨라지나?

### 설정

- **시험 아민:** 4점이 하나라도 있는 아민 31종 (4점이 없는 14종은 찾을 대상이 없어 제외). 1부와 같은 아민 단위 5묶음 분할(시험 20% / 나머지를 학습 60 / 검증 20).
- **후보:** 그 아민으로 실제 수행된 실험 조건들. 전략이 하나를 고르면 그 실험의 실제 점수를 공개하고, 다음을 고릅니다(한 번에 하나씩). 실제로 해 보지 않은 조건은 평가할 수 없어 후보에 넣지 않습니다.
- **상한:** 48번(96칸 판의 절반)까지 4점이 없으면 49번으로 기록하고, 그런 경우의 수를 따로 보고합니다.

### 전략

| 전략 | 방식 | 학습 |
|---|---|---|
| 무작위 | 무작위 순서 (20가지 순서 평균) | 없음 |
| 고르게 훑기 | 이미 한 실험들과 농도가 가장 먼 조건을 다음으로 (시작점 20가지 평균) | 없음 |
| 다른 아민 모델 순서 | 다른 아민으로 학습한 LightGBM의 4점 확률 순서 그대로 | 실험 전에 한 번 |
| 근처 점수 따라가기 | 처음 4번은 고르게 훑기, 그다음부터는 지금까지 결과의 점수(1~4)를 거리 가중 평균한 값이 가장 높은 조건으로 | 없음 (1~3점 사용) |
| 재학습 (4점 여부) | 매 실험 후 다른 아민 데이터 + 지금까지 결과로 LightGBM 분류를 다시 학습, 4점 확률 최대 조건으로 | 매번 (1부 방식) |
| **재학습 (점수 1~4)** | 위와 같지만 점수 1~4를 그대로 예측하는 LightGBM 회귀, 예측 점수 최대 조건으로 | 매번 (1~3점 사용) |

### 모델과 실험 설계

**실험 절차 (후향적 시뮬레이션):** 실제로 새 실험을 하지 않고, 기록된 실험을 "아직 결과를 모르는 후보"로 두고 흉내 냅니다.
1. 시험 아민 하나의 기록된 실험 전체를 후보로 둡니다(점수는 가림).
2. 전략이 후보 하나를 고르면 그 실험의 실제 점수(1~4)를 공개하고, 후보에서 뺍니다.
3. 4점이 나오면 멈추고 그때까지 고른 수(4점 실험 포함)를 기록합니다. 48번까지 없으면 49로 기록합니다.
4. 무작위가 들어가는 전략(무작위, 고르게 훑기의 시작점)은 20번 반복해 평균합니다. 나머지는 결정적이라 한 번 실행합니다.

**거리:** 같은 아민 안에서 PbI₂·아민·포름산 농도 3개를 그 아민 후보들의 평균·표준편차로 표준화한 뒤의 유클리드 거리.

**모델 입력 (1부와 같음):** 농도 3개, 몰비 2개(아민/PbI₂, 포름산/PbI₂), 온도·반응 시간·교반 속도, 아민 분자 특성(아민 간에 값이 다른 것). 1부 EDA 기준으로 이상 실험은 제외.

| 전략 | 모델 | 다음 실험을 고르는 규칙 | 설정 (검증 아민에서 선택) |
|---|---|---|---|
| 무작위 | 없음 | 남은 후보 중 무작위 | – |
| 고르게 훑기 | 없음 | 무작위 시작 → 이미 한 실험들까지의 최소 거리가 가장 큰 후보 | – |
| 다른 아민 모델 순서 | LightGBM 분류 (4점 여부), 학습+검증 아민으로 한 번 학습 | 4점 확률이 높은 순서 그대로 | – |
| 근처 점수 따라가기 | 없음 (커널 가중 평균) | 처음 4번은 고르게 훑기. 그 뒤 후보마다 "지금까지 결과 점수의 가우시안 거리 가중 평균"을 계산해 최대인 후보. 동점이면 고르게 훑기 규칙 | 거리 폭 h = 그 아민 후보 간 최근접 거리 중앙값 × {0.5, 1, 2} |
| 재학습 (4점 여부) | LightGBM 분류. 학습+검증 아민 데이터 + 지금까지 이 아민의 결과(가중치 w)로 매 실험 후 다시 학습 | 4점 확률 최대 후보. 첫 실험은 다른 아민 모델 순서의 1위 | w ∈ {5, 10, 20} |
| 재학습 (점수 1~4) | LightGBM 회귀 (점수 1~4를 숫자로). 나머지 같음 | 예측 점수 최대 후보 | w ∈ {5, 10, 20} |

- LightGBM 크기는 1부에서 가장 자주 선택된 값(잎 15개, 학습률 0.05)으로 고정하고, 매 실험 재학습의 계산량 때문에 나무는 200개로 둡니다.
- **설정 선택:** 묶음마다 검증 아민(시험 아민과 겹치지 않음)에서 위 시뮬레이션을 돌려 평균 "첫 4점까지 실험 수"가 가장 작은 설정을 고릅니다. 이때 모델은 학습 아민으로만 학습합니다.
- **주 판정에 쓸 전략 선택:** 학습을 쓰는 네 전략(다른 아민 모델 순서, 근처 점수 따라가기, 재학습 2종) 중 검증 아민에서 가장 빨랐던 것을 묶음마다 고르고, 시험 아민에서는 그 전략의 결과를 씁니다.

### 지표와 판정

- **주 지표:** 첫 4점까지 실험 수 (아민별 평균 → 아민 31종 평균). 불확실성은 아민 단위 부트스트랩 1,000회의 95% 구간.
- **보조 지표:** 8번·16번 안에 4점을 찾은 아민 비율.

| 판정 | 기준 |
|---|---|
| **주** | 검증 아민에서 가장 빨랐던 학습 사용 전략(다른 아민 모델 순서, 근처 점수 따라가기, 두 재학습 중 하나)이, 시험 아민에서 무작위와 고르게 훑기보다 모두 빠름 (차이의 95% 구간 상한 < 0) |
| 1~3점의 가치 | 재학습(점수 1~4) − 재학습(4점 여부)의 차이 구간 상한 < 0 |
| 참고 | 전략별 곡선(실험 수에 따른 4점 발견 비율), 4점 없이 48번에 도달한 경우 수 |

구간이 0을 포함하면 "우열을 판단할 증거 부족"으로 씁니다.

### 하지 않는 것

뉴로심볼릭 모델. 1부 결과의 재해석이나 기준 변경 (바꾸면 LOG.md에 이유와 함께 기록).
