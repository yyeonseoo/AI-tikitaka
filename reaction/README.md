# 반응 수율 예측: 제약 합성 반응의 조건 → 수율

팔라듐 촉매 짝지음 반응의 시약 조합으로 수율(넣은 출발물질 중 원하는 생성물로 바뀐 비율, %)을 예측하는 머신러닝 연구입니다. 이 파일은 요약이고, 단계별 계획(실행 전 커밋)과 결과 원문은 [LOG.md](LOG.md)에 있습니다.

## 풀려는 문제

신약 공정을 개발할 때 새 출발물질이나 새 시약을 쓰면, 수백 개 조건 조합 중 어느 것이 수율이 높을지 몰라 실험판에 깔아 다 해 봅니다. 수율을 미리 예측하면 해 볼 조건을 줄일 수 있습니다.

## 데이터

[github.com/rxn4chemistry/rxn_yields](https://github.com/rxn4chemistry/rxn_yields)에서 받은 고속 대량 실험(HTE) 데이터 2종 (`reaction/data/`는 git 제외).

| 데이터 | 반응 | 바꾼 것 | 규모 |
|---|---|---|---|
| Buchwald–Hartwig (BH, Ahneman et al., *Science* 2018) | C–N 결합 | 출발물질 15종 (고리 5종 × 할로젠 Cl·Br·I), 리간드 4, 염기 3, 첨가제 22 | 3,955건 |
| Suzuki–Miyaura (SM, Perera et al., *Science* 2018) | C–C 결합 | 친전자체 7 (퀴놀린의 반응 자리 Cl·Br·OTf·I, 붕소 3종), 친핵체 4, 리간드 12, 염기 8, 용매 6 | 5,760건 |

SM 시약 구조는 원 저자들의 반응식에서 자동으로 뽑아 [reagents_sm.csv](reagents_sm.csv)에, 화학 지식 값(이탈기 반응성, 결합 세기, 해밋 상수, 리간드 종류, 염기 pKa, 용매 극성)은 출처와 함께 [knowledge.csv](knowledge.csv)에 있습니다.

## 지금까지의 결과

평가는 그룹 단위로 나눠 시험 그룹의 반응이 학습에 들어가지 않게 했습니다. 오차는 MAE(수율 예측이 평균 몇 %p 틀렸나)이고, 모든 반응을 평균 수율로 찍으면 약 23~24%p입니다.

| 상황 | 단순 방법 | 머신러닝 (LightGBM + 분자 특성) | 결론 |
|---|---|---|---|
| 이미 써 본 시약의 새 조합 (BH 무작위 분할) | 6.8 | **4.0** (R² 0.96) | 머신러닝이 확실히 나음. 공개 최고 수준 |
| 이미 써 본 시약의 새 조합 (SM 무작위 분할) | 10.8 | **6.8** | 머신러닝이 확실히 나음 |
| 처음 보는 출발물질 (BH) | 18.1 | **11.8** | 조건 평균보다 6%p 나음 (재분석). 단 할로젠·고리를 아는 화학자 규칙 모델은 **11.3**으로 같은 수준 (4차, 탐색적) |
| 처음 보는 리간드 (SM, 사전 확인) | **15.0** | 18.2 | 단순 방법이 더 나음. 사전에 정한 확인 실패 |
| 처음 보는 반응 자리 (SM) | 18.7 | 18.5 (화학 지식 추가 시 18.0) | 단순 방법과 차이 불분명. 화학 지식은 확실히 도움 (−0.5%p) |
| 처음 보는 고리 구조 (BH, 고리 통째로 뺌) | 19.4 | **15.2** | 다섯 고리 모두 머신러닝이 나았지만 신뢰구간이 0을 살짝 넘음 (사전 기준 미달) |

- 단순 방법은 "다른 그룹에서 같은 나머지 조건의 평균 수율"(조건 평균)과 "선형 + 시약 짝 상호작용" 중 검증으로 고른 것입니다.
- **분자 구조 정보는 학습 데이터에 비슷한 친척이 있을 때 처음 보는 시약을 맞히는 데 도움이 됩니다.** BH 출발물질은 같은 고리의 다른 할로젠 버전이 학습에 있어서 맞혔고, 서로 구조가 다른 SM 리간드 12종은 못 맞혔습니다.
- 처음 보는 출발물질에서 "1순위로 추천한 조건"의 실제 수율은 단순 방법과 머신러닝 모두 약 60% 수준으로 비슷합니다(가능한 최고 72%). 머신러닝의 이점은 추천 1순위보다 수율 값 자체를 맞히는 데서 나왔습니다.

## 3차 계획: 처음 보는 고리 구조 (2026-10-22, 실행 전 확정)

### 질문

BH에서 처음 보는 출발물질을 맞힌 것이 "같은 고리의 다른 할로젠 버전을 본 덕분"인지, 새로운 고리 구조에도 통하는지 확인합니다.

### 설계

- **분할:** 고리 5종 중 하나를 통째로(그 고리의 Cl·Br·I 출발물질 3종 전부) 시험으로 빼고, 나머지 4종 고리로 학습합니다. 5번 돌려 모든 고리를 한 번씩 시험합니다.
- **설정 고르기:** 학습 고리 4종을 하나씩 빼 가며 검증(고리 하나 빼기). 모델마다 설정 후보 30개.
- **모델 (2차와 같음, 미리 고정):** 조건 평균(같은 리간드·염기·첨가제의 학습 고리 평균, 할로젠은 구분하지 않음), 선형 + 짝 상호작용, LightGBM·분자 특성(주), LightGBM·분자 + 화학 지식, LightGBM·분자 + 화학 지식 + 단조 제약, 신경망·분자 + 화학 지식(참고)
- **화학 지식이 이번에 중요한 이유:** 고리가 통째로 처음 보는 것이라, 고리의 전자 성질(해밋 상수, 피리딘 여부, 질소 위치)이 새 고리를 설명할 수 있는 거의 유일한 정보입니다.
- **지표:** MAE (주), R², 출발물질 안 조건 순위 상관, 1순위 추천의 실제 수율. 불확실성은 시험 출발물질 15종 단위 부트스트랩 1,000회 95% 구간(고리가 5종뿐이라 고리 단위로는 구간을 낼 수 없음; 고리별 결과도 따로 표시).

### 판정

| 판정 | 기준 |
|---|---|
| **주** | LightGBM·분자 특성 − 최선 단순(안쪽 검증 선택)의 MAE 차이 상한 < 0 |
| 화학 지식 | LightGBM·분자 + 화학 지식 − LightGBM·분자 특성의 MAE 차이 상한 < 0 |
| 참고 | 단조 제약, 신경망, 고리별 결과 |

결과 해석: 주 판정이 충족되면 "새 고리 구조의 출발물질도 맞힌다", 미달이면 "같은 고리 친척이 있을 때만 맞힌다"로 정리합니다. 이 데이터는 1·2차에서 결과를 본 데이터라 확인이 아니라 추가 분석입니다.

전체: [results_model3.md](results_model3.md). 여러 번 나눠 실행해서, 결과 파일의 "실행 2분"은 마지막 이어 실행 시간만 적힌 값입니다(전체 약 25분).

- 실행 메모: 온도 감시 스크립트가 멈춘 프로세스가 일부만 멈추는 문제가 있었습니다(가상환경 파이썬이 실제로는 기본 파이썬으로 작업을 띄워, 경로로 찾는 방식이 작업 프로세스를 놓침). 계산 결과에는 영향이 없고, 스크립트는 고쳤습니다.

- 모델이 의존한 특징들이 알려진 반응 메커니즘(산화적 첨가, 촉매 피독, 붕소 활성화)과 맞아떨어져, 예측이 엉뚱한 상관에 기대고 있지 않다는 근거가 됩니다. 다만 SHAP는 모델이 무엇을 썼는지에 대한 설명이고, 인과 관계를 증명하지는 않습니다.

## 4차 계획: 조건 추천 평가 (2026-11-03, 실행 전 확정)

### 왜 하나

외부 피드백에서 세 가지가 지적됐습니다. 지금까지의 대표 결과(처음 보는 출발물질 MAE 18.1 → 11.8)는 사전 주 판정이 아니라 재분석입니다. 비교 대상인 조건 평균은 출발물질 정보(할로젠, 고리)를 전혀 쓰지 않아 너무 약합니다. 그리고 실험실이 실제로 묻는 "어떤 조건부터 해 볼까"를 평가하지 않았습니다. 사전 주 판정 기준으로는 지금까지 머신러닝이 이긴 결과가 없습니다. 4차는 이 빈자리를 사전 계획된 추천 평가로 채웁니다.

### 질문

처음 보는 출발물질에서 모델이 추천한 상위 k개 조건만 실험하면, 최고 조건을 얼마나 놓치지 않는가? 할로젠과 고리 규칙만 쓴 화학자 규칙 모델보다 나은가?

### 설계

- **고르는 조건:** 리간드 4 × 염기 3 = 12개. 첨가제는 고르는 조건이 아니라 주어진 상황입니다. 원 논문이 약물 분자의 작용기를 흉내 내려고 넣은 방해 요소이기 때문입니다.
- **평가 단위:** (출발물질, 첨가제) 한 쌍이 한 상황입니다. 330개 상황 중 325개는 조건 12개, 5개는 측정이 빠져 11개입니다.
- **분할:** 2·3차와 같은 분할을 씁니다. 처음 보는 출발물질(주)과 처음 보는 고리(2차)입니다. 같은 `model.folds()`, 시드 0입니다.

### 비교할 방법

| 방법 | 내용 |
|---|---|
| 무작위 | 상황 안 조건 중 k개를 무작위로 고름. 시뮬레이션이 아니라 기댓값을 계산식으로 구함 |
| 조건 평균 | 같은 리간드·염기·첨가제의 학습 출발물질 평균. 출발물질 정보 없음 (2·3차 저장본) |
| 할로젠별 조건 평균 | 같은 할로젠, 리간드, 염기, 첨가제의 학습 출발물질 평균. 학습에 없는 칸은 조건 평균으로 대체. 할로젠 하나만 아는 가장 간단한 규칙 |
| **화학자 규칙 모델** | 원-핫 능형 회귀. 아래 항 목록 참고. 정규화 강도는 {0.1, 1, 10, 100, 1000} 중 안쪽 그룹 하나 빼기 검증으로 선택 |
| LightGBM + 분자 특성 | 주 모델 (2·3차 저장본 `LGBM·F1 (주)`) |
| LightGBM + 무작위 지문 | 시약마다 분자 특성 대신 같은 개수의 무작위 0/1 값을 고정해서 넣음. 시드 3개(1, 2, 3). 설정 후보 30개와 안쪽 검증은 주 모델과 같음 |

**화학자 규칙 모델의 항 (빠짐없이):**
- **주효과:** 리간드, 염기, 첨가제, 할로젠, 고리
- **조건끼리 짝:** 리간드×염기, 리간드×첨가제, 염기×첨가제
- **할로젠과 조건 짝:** 할로젠×리간드, 할로젠×염기, 할로젠×첨가제
- **고리와 조건 짝:** 고리×리간드, 고리×염기, 고리×첨가제
- **넣지 않는 항:** 할로젠×고리. 처음 보는 출발물질 분할에서 이 항은 곧 그 출발물질의 식별자라 시험 때 한 번도 학습되지 않습니다.
- **처음 보는 고리 분할:** 시험 고리의 고리 항은 학습에 없어서 0입니다. 이 경우 모델은 할로젠 항과 조건 항만으로 예측합니다.

### 지표

- **주 지표 regret@3:** 상황 안 실제 최고 수율 − 추천 상위 3개 조건 중 실제 최고 수율 (%p, 낮을수록 좋음). 상황마다 계산해 평균합니다.
- **보조 지표:**
  - 상위 k개 적중률 (k = 1, 2, 3, 5): 상위 k개 안에 실제 최고 수율과 같은 조건이 있으면 적중. 최고 수율이 같은 조건이 여러 개면 그중 하나만 들어 있어도 적중입니다.
  - regret@k (k = 1, 2, 5)
  - 최고와 5%p 이내 조건을 찾을 때까지 필요한 실험 수 (추천 순서대로 실험)
  - 상황 안 순위 상관 (Spearman), MAE

**조건 수와 동점 처리:**
- 모든 지표는 그 상황에 실제로 있는 조건만으로 계산합니다. 무작위 기댓값도 상황마다 그 조건 수로 계산합니다.
  - regret@k: 정렬된 수율에서 i번째가 최댓값일 확률 C(i−1, k−1)/C(n, k)로 구함
  - 적중률: 1 − C(n−m, k)/C(n, k), m은 최고 수율 조건 수
  - 필요 실험 수: (n+1)/(m+1), m은 5%p 이내 조건 수
- 예측값이 같은 조건이 있으면 시드 0으로 무작위로 순서를 정하고, 동점 수를 보고합니다.
- 민감도 분석: 조건이 11개인 5개 상황을 빼고 다시 계산합니다.

### 판정

| 구분 | 비교 | 기준 |
|---|---|---|
| **주 (하나만)** | 처음 보는 출발물질, regret@3, LightGBM + 분자 특성 − 화학자 규칙 모델 | 출발물질 15종 단위 부트스트랩 1,000회 95% 구간. 상한 < 0이면 충족, 0을 포함하면 우열 판단 증거 부족, 하한 > 0이면 반대 방향 |
| 2차 (기술 보고) | 같은 비교를 처음 보는 고리에서 | 같은 방식, 헤드라인에 쓰지 않음 |
| 2차 (기술 보고) | 각 방법 − 무작위, LightGBM − 조건 평균, 화학자 규칙 − 할로젠별 조건 평균 | 〃 |

2단계 부트스트랩의 단서: 첨가제 22종은 무작위 표본이 아니라 원 논문이 고른 설계입니다. 그래서 이 분석은 "다른 첨가제 세트였다면 구간이 얼마나 흔들렸을까"를 보는 민감도이고, 첨가제 일반화를 주장하는 근거로 쓰지 않습니다.

### 미리 적는 예상

- 모든 방법이 무작위보다 낫다.
- 화학자 규칙 모델은 조건 평균보다 낫다.
- **주 판정은 우열 판단 증거 부족**일 가능성이 높다.
- 무작위 지문은 처음 보는 출발물질에서 분자 특성보다 나쁘다.

예상대로 나오면 결론은 "추천은 규칙만으로도 충분했다"입니다. 무작위 대비 실험 절감은 2차 판정의 기술 보고로 함께 적습니다.

### 알려 둔 한계

- LightGBM과 조건 평균의 예측값은 2·3차 저장본입니다. 출발물질 단위 1순위 추천 수율(60.0 대 63.2)은 이미 봤기 때문에 완전히 새로운 시험은 아닙니다. 새 비교 대상(화학자 규칙 모델, 할로젠별 조건 평균)과 새 지표(상황 단위 regret@3)는 결과를 보기 전에 정합니다.
- 출발물질 15종 안의 보간입니다. 같은 고리의 다른 할로젠, 같은 할로젠의 다른 고리가 학습에 남아 있습니다.
- 범위: 단순 할로아렌 15종, 아민은 p-톨루이딘 하나로 고정입니다.

### 4차 결과 (2026-11-03)

전체: [results_model4.md](results_model4.md), 그림 [figures/model4_topk.png](figures/model4_topk.png). 실행 약 17분입니다(온도 감시로 여러 번 쉬었고, 결과 파일의 "3분"은 마지막 재시작 구간만 잰 값).

**주 판정: 우열 판단 증거 부족.** 처음 보는 출발물질에서 regret@3의 차이(LightGBM − 화학자 규칙 모델)는 −0.24 [−0.69, +0.10]%p입니다. 2단계 부트스트랩(−0.24 [−0.74, +0.15])에서도, 조건 11개 상황을 뺐을 때(−0.24 [−0.69, +0.11])도 같습니다. 예상과 일치합니다.

| 처음 보는 출발물질 | 상위 3개 적중률 | regret@3 (%p) | 최고와 5%p 이내 조건까지 실험 수 |
|---|---|---|---|
| 무작위 | 25% | 8.4 | 3.9번 |
| 조건 평균 (출발물질 정보 없음) | 81% | 0.7 | 1.4번 |
| 할로젠별 조건 평균 | 83% | 0.8 | 1.3번 |
| 화학자 규칙 모델 | 84% | 0.8 | 1.4번 |
| LightGBM + 분자 특성 | 85% | 0.6 | 1.3번 |
| LightGBM + 무작위 지문 (시드 3개 평균) | 74% | 1.1 | 1.5번 |

- **추천은 무작위보다 크게 낫습니다 (2차, 기술 보고).**
  - 최고와 5%p 이내 조건을 찾는 데 무작위는 평균 3.9번이 필요한데, 데이터 기반 추천은 1.3~1.4번이면 됩니다(약 65% 감소).
  - 상위 3개만 실험해도 최고 조건이 들어 있을 확률은 81~85%로, 무작위의 25%보다 훨씬 높습니다.
  - regret@3: 화학자 규칙 −7.6 [−9.8, −5.5], LightGBM −7.9 [−9.8, −6.0]%p
- **추천에는 출발물질 정보가 거의 필요 없었습니다.**
  - 출발물질 정보를 전혀 쓰지 않는 조건 평균만으로도 효과 대부분이 나옵니다. 좋은 리간드·염기 조합(예: tBuXPhos + MTBD)이 출발물질이 달라도 대체로 같기 때문입니다.
  - LightGBM − 조건 평균은 −0.12 [−0.27, +0.07]로, 증거 부족입니다.
  - regret 값 자체가 작은 데에는 이유가 하나 더 있습니다. C–Cl처럼 어떤 조건에서도 수율이 낮은 출발물질은 최고와 차이가 원래 작게 나옵니다.
- **분자 특성은 무작위 지문보다 낫습니다 (Chuang & Keiser 반론에 대한 답, 2차).**
  - 무작위 지문 − 분자 특성의 regret@3은 +0.54 [+0.18, +0.92]입니다. 결과 표에 "반대 방향"으로 나온 것은 비교 순서 때문이고, 예상대로 분자 특성이 나았다는 뜻입니다.
  - 고리 분할에서는 +0.46 [+0.13, +0.84]입니다.
  - MAE는 분자 특성 11.8, 무작위 지문 19.0~23.8입니다. 그룹 분할에서는 무작위 특성이 일반화되지 않습니다.
- **처음 보는 고리 (2차):** LightGBM − 화학자 규칙은 +0.02 [−0.52, +0.48]로 증거 부족입니다. 두 방법 모두 무작위보다 약 7.8%p 낫습니다.
- **SM 리간드 민감도:** "리간드 없음"을 평가에서 빼도 단순 방법이 낫습니다(LightGBM − 단순 +2.78 [+0.92, +4.86]). 결론은 바뀌지 않습니다.

**탐색적 관찰 (계획에 없던 비교, 판정에 쓰지 않음):**
- 수율 값 자체(MAE)를 보면 처음 보는 출발물질에서 화학자 규칙 모델이 11.30 [9.02, 13.83]으로, LightGBM 11.82 [8.97, 15.36]과 차이가 없습니다(+0.52 [−1.30, +3.14]).
- 처음 보는 고리에서는 화학자 규칙 16.05, LightGBM 15.21입니다(−0.84 [−3.88, +2.99]).
- 화학자 규칙 − 할로젠별 조건 평균은 출발물질 분할에서 −4.57 [−7.64, −1.32]입니다. 수율 값을 맞히는 데는 고리 정보와 조건 짝 효과가 중요했습니다.
- 그러니 2차에서 보고한 "LightGBM 11.8 대 조건 평균 18.1"의 차이는 대부분 **할로젠과 고리라는 단순한 화학 규칙으로 설명됩니다.** 머신러닝이 그 이상을 배웠다는 증거는 없습니다.

**정리:**
- 처음 보는 출발물질에 대해 조건을 추천하면 무작위보다 실험이 약 65% 줄어듭니다.
- 하지만 그 효과는 출발물질 정보가 없는 조건 평균으로도 대부분 나옵니다.
- 수율 값을 맞히는 데는 할로젠·고리 규칙이 핵심이었습니다. 이 데이터 범위에서 LightGBM은 그 규칙을 넘어서지 못했습니다.
- 분자 특성 자체는 무작위 특성보다 분명히 쓸모가 있습니다.

## 5차 계획: SM 순차 조건 최적화 (2026-11-03, 실행 전 확정)

### 왜 하나

지금까지 처음 보는 시약으로 넘어가는 문제에서는 머신러닝이 단순 모델보다 낫지 않았습니다(BH 비김, SM 리간드는 단순 쪽이 나음). 반면 모든 시약이 학습에 나온 SM 무작위 분할에서는 LightGBM이 선형 + 짝 상호작용보다 크게 나았습니다(MAE 6.80 대 10.79). 실험실에서 이 장점이 쓰이는 곳은 "가진 시약 안에서 최고 조건을 적은 실험으로 찾기"입니다. 5차는 이것을 과거 데이터로 재현해 봅니다(실험 대신 데이터셋의 수율을 꺼내 씀).

### 질문

새 출발물질 쌍의 조건을 4개씩 묶어 실험하며 찾을 때, LightGBM이 다음 실험을 고르면 선형 모델이 고를 때보다 최고 조건에 더 빨리 가까워지는가?

### 설계

- **목표:** (출발물질, 짝 출발물질) 한 쌍. 15쌍이며 쌍마다 조건(리간드 12 × 염기 8 × 용매 4) 384개가 모두 측정되어 있습니다.
- **과거 데이터 있음 (주):** 나머지 14쌍의 데이터 5,376개를 처음부터 학습에 씁니다. 실험실에 지난 HTE 데이터가 있는 상황입니다.
- **과거 데이터 없음 (2차):** 목표 쌍의 실험만으로 학습합니다.
- **진행:** 목표 쌍에서 무작위 4개로 시작 → 모델 학습 → 아직 안 한 조건 중 점수 상위 4개 실험 → 반복 9번. 총 40개(384개의 약 10%).
- **반복:** 시작 4개를 시드 0~9로 바꿔 10번. 같은 시드면 모든 방법이 같은 시작 4개를 씁니다.
- **동점:** 점수가 같으면 무작위 순서.

### 비교할 방법

| 방법 | 내용 |
|---|---|
| 무작위 | 384개 중 n개를 무작위로 실험. 계산식 기댓값 |
| 과거 평균 순서 (과거 데이터 있음만) | 과거 14쌍에서 같은 리간드·염기·용매의 평균 수율 순서대로 실험. 학습에 없는 용매 조합은 리간드·염기 평균으로 대체. 갱신 없음 |
| **선형 모델** | 베이지안 능형 회귀(sklearn `BayesianRidge`, 기본 설정). 과거 데이터 있음: 다섯 자리 원-핫 + 모든 두 자리 짝(4차 화학자 규칙과 같은 생각, SM판). 과거 데이터 없음: 리간드·염기·용매 원-핫만 |
| **LightGBM** | RDKit 분자 특성 F1 (2차와 같음). 설정 고정: 나무 300개, 학습률 0.05, 잎 31, 잎당 최소 10(과거 데이터 없음: 잎 7, 최소 3), 행·열 표본 0.8. 시드 0~4로 5개를 학습해 평균과 표준편차를 씀 |

**고르는 점수:**
- 주: 예측 평균이 높은 순(탐욕적 선택). 모델 차이만 비교하려고 불확실성 크기 차이는 뺐습니다.
- 2차: UCB = 평균 + 1 × 표준편차 (베이지안 최적화의 대표 방식).

### 지표

- **주 지표 regret@20:** 그 쌍의 최고 수율 − 20번 실험까지 찾은 최고 수율 (%p). 시드 10개 평균을 쌍마다 구합니다.
- **보조:** regret@8, @12, @40, 최고와 5%p 이내 조건을 40번 안에 찾은 비율, 찾을 때까지 실험 수(못 찾으면 41로 셈), 실험 수에 따른 곡선.

### 판정

| 구분 | 비교 | 기준 |
|---|---|---|
| **주 (하나만)** | 과거 데이터 있음, 탐욕적 선택, regret@20, LightGBM − 선형 모델 | 15쌍 단위 부트스트랩 1,000회 95% 구간. 상한 < 0이면 충족, 0을 포함하면 우열 판단 증거 부족, 하한 > 0이면 반대 방향 |
| 2차 | 같은 비교를 UCB로, 과거 데이터 없음으로 | 같은 방식, 헤드라인에 쓰지 않음 |
| 2차 | 각 방법 − 무작위, 각 방법 − 과거 평균 순서 | 〃 |

### 미리 적는 예상

- 무작위 분할에서 LightGBM이 크게 나았으므로 주 판정 충족 가능성은 반반보다 조금 높다고 봅니다.
- 다만 시작 시점에 목표 쌍 정보가 거의 없어 이번 문제는 무작위 분할보다 어렵습니다. 짧은 확인에서 쌍 하나(1a + 2a)를 통째로 빼고 예측해 보니, 상위 4개 안에 든 최고 수율이 선형 93.7(그 쌍의 최고), LightGBM 91.3이었습니다. 선형이 이길 수도 있습니다.
- 과거 평균 순서도 강할 수 있습니다. 4차에서 조건 평균이 강했던 것과 같은 이유입니다.

### 알려 둔 한계

- 과거 데이터로 재현한 것이라 실제 실험의 잡음과 시간은 없습니다.
- 쌍이 15개뿐이고 출발물질은 퀴놀린·인다졸 한 종류의 변형입니다.
- LightGBM 설정은 튜닝하지 않고 고정했습니다(순차 과정 안에서 튜닝하면 계산이 너무 큼). 선형 모델도 기본 설정입니다.

- 과거 데이터가 없으면 이점이 작아집니다(무작위 대비 2~3%p). 처음 몇 라운드는 모든 방법이 무작위와 비슷합니다.
- 그림에서 과거 평균 순서가 처음 4번 동안 앞서는 것은, 모델 방법들이 처음 4개를 무작위로 시작하도록 설계했기 때문입니다.

**정리 (5차):** 4차와 같은 결론이 순차 탐색에서도 나왔습니다. 데이터로 실험 순서를 정하면 실험이 크게 줄지만, 그 효과의 대부분은 짝 상호작용이 있는 선형 모델로도 얻습니다. LightGBM은 일관되게 조금 앞서지만 15쌍으로는 그 차이를 입증하지 못했습니다.

## 6차 계획: SM 조건 추천 (2026-11-03, 실행 전 확정)

### 질문

처음 보는 출발물질 쌍에서 실험을 하나도 하지 않고 384개 조건에 순위를 매길 때, 같은 분자 특성을 넣은 선형 회귀보다 LightGBM의 상위 추천이 더 좋은가? 4차(BH, 조건 12개)의 SM판이며, 고를 조건이 384개라 추천 능력 차이가 더 잘 드러날 수 있습니다.

### 설계

- **목표:** 5차와 같은 15쌍. 쌍마다 나머지 14쌍(5,376개)으로만 학습하고, 목표 쌍의 384개 조건(리간드 12 × 염기 8 × 용매 4)에 순위를 매깁니다. 목표 쌍의 실험은 0개입니다.
- **동점:** 예측값이 같으면 시드 0으로 무작위 순서.

### 비교할 방법

| 방법 | 내용 |
|---|---|
| 무작위 | 계산식 기댓값 |
| 과거 평균 순서 | 5차와 같음 (같은 리간드·염기·용매의 과거 14쌍 평균, 없으면 리간드·염기 평균) |
| 선형 + 짝 상호작용 | 5차의 선형 모델과 같음 (`BayesianRidge`, 다섯 자리 원-핫 + 모든 두 자리 짝) |
| **선형 회귀 + 분자 특성** | F1(RDKit 분자 특성)을 표준화해 능형 회귀. 정규화 강도는 {0.1, 1, 10, 100, 1000} 중 학습 14쌍 안에서 쌍 하나 빼기 검증 MAE로 선택 |
| **LightGBM + 분자 특성** | 5차와 같은 고정 설정 5개 묶음의 평균 예측 |

### 지표

- **주 지표 regret@8:** 그 쌍의 최고 수율 − 추천 상위 8개(HTE 두 묶음) 중 최고 수율 (%p).
- **보조:** regret@1, @4, @20; 상위 k개(4, 8, 20) 안에 최고와 5%p 이내 조건이 있을 확률; 쌍 안 순위 상관(Spearman); MAE.

### 판정

| 구분 | 비교 | 기준 |
|---|---|---|
| **주 (하나만)** | regret@8, LightGBM + 분자 특성 − 선형 회귀 + 분자 특성 | 15쌍 단위 부트스트랩 1,000회 95% 구간. 상한 < 0이면 충족, 0을 포함하면 우열 판단 증거 부족, 하한 > 0이면 반대 방향 |
| 2차 | LightGBM − 선형 + 짝 상호작용, LightGBM − 과거 평균 순서, 각 방법 − 무작위 | 같은 방식, 헤드라인에 쓰지 않음 |

### 미리 적는 예상

- 사후 분석(BH)에서 같은 분자 특성의 선형보다 LightGBM이 나았고, SM 무작위 분할에서도 LightGBM이 크게 나았으므로 주 판정 충족 가능성은 반반보다 조금 높다고 봅니다.
- 5차 첫 라운드 전 상태와 같은 문제라, 역할이 바뀐 반응(1e~1g)에서는 모든 방법이 어려울 것으로 봅니다.
- 쌍이 15개뿐이라 구간이 넓을 수 있습니다.

| 방법 | regret@1 | regret@8 | 상위 8개 안에 최고 근처 | 상위 20개 안에 최고 근처 | 순위 상관 |

**해석:**
- **사전에 정한 주 판정에서 머신러닝이 처음으로 이겼습니다.** 같은 분자 특성을 넣었을 때 LightGBM의 상위 8개 추천은 선형 회귀보다 최고 수율에 평균 10%p 가깝습니다.
- 선형 회귀 + 분자 특성은 과거 평균 순서보다도 나쁩니다. 시약별 분자 특성을 더하기만 하는 모델은 "이 출발물질에는 이 리간드" 같은 조합 효과를 표현하지 못합니다. 염소 출발물질(1a)에서 50%p 이상 놓친 것이 대표적입니다.
- 조합 효과를 원-핫 짝으로 직접 넣은 선형 모델(2차)과 비교해도 LightGBM이 작지만 확실하게 낫습니다(−1.29 [−2.96, −0.28]). 5차 순차 탐색에서 같은 비교가 증거 부족이었던 것과 달리, 실험 0개에서 한 번에 추천하는 상황에서는 차이가 드러났습니다.
- 차이는 주로 출발물질 쪽 정보가 적은 쌍(1e + 2d, 1b + 2a 등)에서 나옵니다. 1f, 1g처럼 모든 방법이 어려운 쌍도 남아 있습니다.
- 쌍이 15개라 구간이 넓습니다(주 판정 상한 −2.7).

**정리 (4~6차):** 데이터 기반 추천은 무작위보다 실험을 크게 줄입니다(BH 약 65%, SM 순차 탐색 약 50%). 같은 분자 특성을 쓸 때는 LightGBM이 선형 회귀보다 확실히 낫고(BH 사후 분석, SM 6차 주 판정), 고를 조건이 많은 SM 첫 추천에서는 조합 항을 직접 넣은 선형 모델보다도 낫습니다. 반면 조건이 12개뿐인 BH 추천과 결과를 보며 고르는 순차 탐색에서는 짝 상호작용 선형 모델과 차이를 입증하지 못했습니다.
