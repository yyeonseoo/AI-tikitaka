# 반응 수율 HTE 데이터: 빠른 확인 (2026-10-22)

"머신러닝으로 단순한 모델보다 확실히 나은 성능을 낼 여지가 있는 데이터"를 찾으려고 확인한 결과입니다.

## 데이터

둘 다 제약회사 방식의 고속 대량 실험(HTE)으로, 한 반응에 들어가는 시약을 칸마다 바꿔 가며 모든 조합의 수율(생성물이 얼마나 생겼나, %)을 잰 데이터입니다. [github.com/rxn4chemistry/rxn_yields](https://github.com/rxn4chemistry/rxn_yields)에서 받았습니다 (`reaction/data/`는 git 제외).

| 데이터 | 반응 | 바꾼 것 | 규모 |
|---|---|---|---|
| Buchwald–Hartwig (Ahneman et al., *Science* 2018) | 팔라듐 촉매로 C–N 결합 만들기 (의약품 합성에 흔함) | 리간드 4, 첨가제 22, 염기 3, 할로젠화 아릴 15 | 3,955건 |
| Suzuki–Miyaura (Perera et al., *Science* 2018) | 팔라듐 촉매로 C–C 결합 만들기 | 친전자체 7, 친핵체 4, 리간드 12(없음 포함), 염기 8, 용매 6 | 5,760건 |

## 확인한 것

입력은 칸마다 어떤 시약을 썼는지(범주)이고, 예측 대상은 수율입니다. 두 가지로 나눠 봤습니다.
- 무작위 5겹: 반응을 무작위로 섞어 나눔
- 처음 보는 시약: 첨가제(BH) 또는 리간드(SM) 하나를 통째로 학습에서 빼고 맞힘

| 모델 | BH 무작위 R² | BH 처음 보는 첨가제 R² | SM 무작위 R² | SM 처음 보는 리간드 R² |
|---|---|---|---|---|
| 선형 (시약마다 평균 효과를 더함) | 0.700 | 0.551 | 0.505 | 0.350 |
| 선형 + 시약 짝 상호작용 | 0.871 | 0.630 | 0.749 | 0.461 |
| LightGBM | **0.939** | 0.605 | **0.851** | 0.348 |
| 랜덤 포레스트 | 0.896 | 0.519 | 0.844 | 0.406 |

## 결과

- RAPID나 전해질과 달리, **단순한 모델과 머신러닝의 차이가 큽니다.** 무작위 분할에서 선형 0.70 → LightGBM 0.94 (BH), 0.51 → 0.85 (SM). 수율이 "어떤 리간드가 어떤 염기·기질과 같이 쓰일 때만 잘 된다" 같은 조합 효과로 정해지기 때문입니다.
- **처음 보는 시약을 맞히는 건 아직 어렵습니다.** 모든 모델이 0.35~0.63이고, 상호작용을 넣은 선형 모델이 가장 낫거나 비슷합니다. 시약을 이름(범주)으로만 넣었기 때문이고, 시약의 분자 특성을 입력으로 넣으면 개선될 여지가 있습니다. 이 부분이 모델 튜닝과 개선을 해 볼 곳입니다.
- 이미 많이 연구된 데이터입니다. 새로움보다는 "같은 데이터에서 모델을 단계적으로 개선하고 비교하는" 연습과 서비스 시제품에 적합합니다.

실행: `python reaction/quick_check.py` (약 1~2분)

## 계획: 처음 보는 기질과 시약의 반응 수율 예측과 조건 추천 (2026-10-22, 실행 전 확정)

### 풀려는 문제

신약 공정 개발에서 새 출발물질(기질)을 반응시킬 때, 리간드·염기·첨가제 조합 수백 개 중 어느 것이 수율이 높을지 모릅니다. 지금은 실험판에 조합을 깔아 다 해 봅니다. **처음 보는 기질(또는 시약)에 대해 수율을 미리 예측하고, 해 볼 조건을 추천**하는 것이 목표입니다.

### 데이터

- **주 데이터: Buchwald–Hartwig** (3,955건). 시약 구조(SMILES)가 있어서 분자 특성을 계산할 수 있습니다. 출발물질(할로젠화 아릴) 15종 × 리간드 4 × 염기 3 × 첨가제 22 조합이고, 출발물질 하나당 조건이 약 264개입니다.
- **보조 데이터: Suzuki–Miyaura** (5,760건). 시약 이름만 있어서 범주 입력으로만 비교합니다. 빈 리간드 칸은 "리간드 없음"으로 둡니다.

### 데이터 분할 (학습 60 / 검증 20 / 시험 20, 그룹 단위)

같은 기질이나 시약의 반응이 학습과 시험에 함께 들어가지 않게, 그룹 단위로 나눕니다.

| 평가 | 그룹 | 의미 |
|---|---|---|
| **주: 처음 보는 기질 (BH)** | 할로젠화 아릴 15종 | 새 출발물질을 받았을 때. 실제 공정 개발에서 가장 흔한 상황 |
| 보조: 처음 보는 첨가제 (BH) | 첨가제 22종 | 원 논문(Ahneman 2018)이 쓴 평가와 같은 종류 |
| 보조: 처음 보는 리간드 (SM) | 리간드 12종 | |
| 참고: 무작위 (BH, SM) | 반응 | 공개된 최고 성능(R² 약 0.95)과 비교용 |

그룹을 5묶음으로 나눠 묶음마다 한 번씩 시험(20%)으로 쓰고, 나머지 그룹을 다시 학습 60 / 검증 20(그룹 단위)으로 나눕니다. 모델 설정은 검증 그룹으로만 고르고, 시험 그룹은 마지막 채점에만 씁니다.

### 입력

| 묶음 | 내용 |
|---|---|
| F0: 시약 이름 | 칸마다 어떤 시약을 썼는지 (범주) |
| F1: 분자 특성 | RDKit으로 시약마다 계산한 값. 분자량, 극성 표면적, logP(물보다 기름에 녹는 정도), 고리 수 등 2D 특성 + 분자 구조 지문(Morgan, 비트 수를 줄여서). BH만 |
| F2: 합성 특성 (F1에 추가) | ① 기질 분해: 할로젠 종류(Cl·Br·I, 반응성 순서 Cl < Br < I)와 할로젠을 뺀 방향족 고리 부분(5종)을 따로 표시. 같은 고리의 다른 할로젠 기질이 학습에 있으면 그 정보를 쓸 수 있게 함 ② 조건 평균 수율: 학습 기질들에서 같은 조건(리간드·염기·첨가제)의 평균 수율, 시약 하나·시약 짝(리간드×염기 등)별 평균 수율, 같은 할로젠 기질만의 조건 평균 수율. 학습 데이터 안에서도 자기 기질을 뺀 값으로 계산해 정답이 섞이지 않게 함 |

### 모델

| 종류 | 모델 |
|---|---|
| **단순 기준선** | ① 조건 평균: 새 기질의 어떤 조건 수율 = 학습 기질들에서 같은 (리간드, 염기, 첨가제) 조건의 평균 수율 ② 선형 (시약 효과 더하기) ③ 선형 + 시약 짝 상호작용 |
| 머신러닝 | LightGBM, 랜덤 포레스트, 신경망(MLP). 각각 F0, F1, F2 입력 |
| 튜닝 | 모델마다 설정 후보 30개를 무작위로 뽑아 검증 그룹의 MAE로 선택 (LightGBM: 잎 수, 나무 수, 학습률, 최소 잎 크기, 특성 비율 등) |

조건 평균(①)은 "다른 기질에서 잘 된 조건은 새 기질에서도 잘 된다"는 가장 단순한 추천 방식입니다. 머신러닝이 이것보다 나아야 의미가 있습니다.

### 지표

- **MAE (주):** 수율 예측 오차의 평균 (%p). 작을수록 좋음
- R²
- **추천 지표:** 시험 기질마다 약 264개 조건을 예측 수율 순으로 줄 세운 뒤
  - 1순위 추천 조건의 실제 수율, 그 기질에서 가능한 최고 수율과의 차이
  - 상위 10개 추천 중 실제 상위 10% 조건의 비율 (무작위면 0.10)
- 불확실성: 그룹 단위 부트스트랩 1,000회의 95% 구간. 처음 보는 기질은 그룹이 15개뿐이라 구간이 넓을 수 있습니다.

### 판정 (실행 전 고정)

| 판정 | 기준 |
|---|---|
| **주** | 처음 보는 기질(BH)에서, 검증으로 고른 최선의 머신러닝 모델 − 검증으로 고른 최선의 단순 기준선의 MAE 차이 95% 구간 상한 < 0 |
| 분자 특성의 가치 | 처음 보는 첨가제(BH)에서 같은 모델의 F1 − F0 MAE 차이 상한 < 0 |
| 합성 특성의 가치 | 처음 보는 기질(BH)에서 같은 모델의 F2 − F1 MAE 차이 상한 < 0 |
| 참고 | 추천 지표, 무작위 분할 성능(공개 최고치와 비교), Suzuki 결과 |

구간이 0을 포함하면 "우열을 판단할 증거 부족"으로 씁니다.

### 단계

| 단계 | 할 일 | 예상 시간 |
|---|---|---|
| 1. 준비 | RDKit 설치(requirements.txt에 추가), 시약 분자 특성 계산 | 15분 |
| 2. EDA | 수율 분포, 수율 0% 비율, 시약별 효과 크기, 상호작용이 얼마나 큰지 | 15분 |
| 3. 기준선 | 단순 기준선 3개를 모든 분할에서 | 15분 |
| 4. 튜닝·평가 | 머신러닝 3종 × 입력 3종 튜닝 → 시험 채점 → 판정 | 30~60분 |
| 5. 해석·시연 | SHAP으로 무엇이 수율을 좌우하는지, 새 기질 하나를 넣으면 추천 조건을 보여 주는 예시 | 30분 |

## 1·2단계 결과: 준비와 EDA (2026-10-22)

전체: [results_eda.md](results_eda.md), 그림 [figures/eda_summary.png](figures/eda_summary.png). 실행: `python reaction/prepare.py` (데이터·분자 특성 확인), `python reaction/eda.py`.

- **준비:** RDKit으로 시약마다 분자 특성(2D 특성 12개 + 구조 지문 64비트, 값이 다 같은 열은 뺌)을 계산했습니다. 할로젠화 아릴 15종은 방향족 고리 5종 × 할로젠 3종(Cl·Br·I)으로 나뉩니다. 할로젠 자리를 표시해서 2-피리딜과 3-피리딜을 구분했습니다.
- **수율 분포 (BH):** 평균 33%, 1% 미만이 10%, 80% 이상이 7%.
- **무엇이 수율을 정하나 (BH):** 기질 하나가 수율 차이의 43%를 설명하고, 첨가제 15%, 리간드 8%, 염기 5%입니다. 시약 효과를 더하기만 하면 71%, 시약 짝 효과까지 넣으면 90%가 설명됩니다(학습 데이터 안). 짝 효과 중에서는 첨가제 × 기질, 리간드 × 기질이 큽니다. Suzuki도 짝 효과가 27%를 더 설명합니다.
- **할로젠:** 평균 수율이 I 45.7%, Br 38.4%, Cl 15.1%입니다. 알려진 반응성 순서(Cl < Br < I)와 같고, 특히 Cl은 크게 낮습니다. 합성 특성(F2)의 할로젠 정보가 쓸모 있을 근거입니다.
- **최고 조건이 몰려 있음:** 기질 15종 중 7종에서 같은 (리간드, 염기) 조합이 최고였습니다. 리간드 1·2와 염기 3이 대체로 좋습니다. 그래서 "다른 기질에서 잘 된 조건"이라는 조건 평균 기준선이 추천에서는 강할 것으로 예상합니다.
- **처음 보는 기질의 어려움:** 기질 자체가 수율 차이의 43%를 차지해서, 새 기질의 전체 수율 수준을 맞히는 게 핵심입니다. 같은 고리의 다른 할로젠 기질이 학습에 있으면 도움이 될 것입니다.
