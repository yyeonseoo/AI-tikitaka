# v1 Baseline: 공정 조건 → PCE

**목적:** 30분 안에 만든 최소 기준선입니다. 이후 버전이 넘어야 할 점수를 정하는 용도입니다.
**코드:** [models/v1_baseline/baseline.py](../models/v1_baseline/baseline.py)
**재현:** `python models/v1_baseline/baseline.py` (데이터 다운로드와 리포트는 `... baseline.py 1`)

## 1. 데이터와 정제 기준

| 단계 | 행 수 | 기준 |
|---|---|---|
| NOMAD 전체 | 51,640 | NOMAD 검색 API로 받음 (2026-10-01). `"Unknown"`은 결측으로 처리 |
| MAPbI3 + one-step 스핀코팅 | 17,866 | `Perovskite_composition_short_form == "MAPbI"`, `Perovskite_deposition_procedure == "Spin-coating"` |
| 입력·PCE 결측 제거 | **12,823 (논문 2,591편)** | 어닐링 온도·시간이 숫자로 바뀌지 않거나 결측인 행, 용매·DOI·PCE가 결측인 행 제거 |

- **v1에 없는 정제:** LLM 추출 행, 실내광 측정, PCE ≤ 0, 중복 행을 걸러내지 않았습니다. 이 기준들은 EDA 이후에 정했습니다([eda_report.md](eda_report.md) 0절).
- **단계적 어닐링:** `65; 100` 같은 값은 숫자로 바뀌지 않아 결측으로 버려졌습니다(전체의 약 14%).

## 2. 입력 변수

| 변수 | DB 컬럼 | 처리 |
|---|---|---|
| 어닐링 온도 (°C) | `Perovskite_deposition_thermal_annealing_temperature` | 숫자 변환 |
| 어닐링 시간 (분) | `Perovskite_deposition_thermal_annealing_time` | 숫자 변환 |
| 주 용매 | `Perovskite_deposition_solvents` | 첫 공정 단계(`>>` 앞)의 용매. 상위 4개 + other |
| 첨가제 유무 | `Perovskite_additives_compounds` | 빈칸 또는 `Undoped`이면 0, 아니면 1 |

**타깃:** `JV_default_PCE`

주 용매 분포는 DMF 5,073행, DMF;DMSO 3,913행, DMSO;GBL 2,087행, DMSO 669행, other 1,081행입니다.

## 3. 모델과 점수

- **분할:** `GroupShuffleSplit`(DOI 단위, test 20%, seed 0)으로 나눠 train 10,296행, test 2,527행입니다. 같은 논문이 양쪽에 섞이지 않습니다.
- **모델:** `HistGradientBoostingRegressor`이고, 하이퍼파라미터는 기본값 그대로 썼습니다(튜닝 없음).

| 모델 | MAE (%p) | R² |
|---|---|---|
| train 평균으로 예측 | 3.88 | −0.006 |
| **HistGradientBoosting** | **3.50** | **0.136** |

## 4. 추천 예시 (4단계)

온도 60~160°C(10°C 간격), 시간 5~120분, 용매 4종, 첨가제 유무를 격자로 만들어 예측했습니다. 예측 PCE 상위 5개 조건과, 각 조건에 가장 가까운 실제 DB 사례입니다.

| 순위 | 조건 | 예측 PCE | 가장 가까운 실제 사례 (DOI: 실제 PCE) |
|---|---|---|---|
| 1 | 80°C, 5분, DMF;DMSO, 첨가제 있음 | 18.97% | nanoen.2019.02.009: 20.71% · advs.201700484: 18.60% · acsnano.7b08561: 0.60% |
| 2 | 70°C, 5분, DMF;DMSO, 첨가제 있음 | 18.87% | adma.201604048: 15.79%, 17.70% · c8ta01237g: 15.30% |
| 3 | 100°C, 15분, DMSO, 첨가제 있음 | 18.86% | jacs.6b08347 (3건): 19.1~19.4% |
| 4 | 100°C, 20분, DMSO, 첨가제 있음 | 18.73% | jacs.6b08347 (3건): 19.1~19.4% |
| 5 | 90°C, 5분, DMF;DMSO, 첨가제 있음 | 18.18% | adma.201903559 (3건): 18.6~21.1% |

## 5. 한계

1. **설명력이 낮습니다(R² 0.14).** 입력이 4개뿐이고, PCE와 가장 관련이 큰 반용매, DMSO 비율, 소자 구조, ETL/HTL, 출판 연도가 빠져 있습니다.
2. **첨가제 정의가 틀렸을 가능성이 큽니다.** 빈칸(64%)을 "첨가제 없음"으로 처리했지만, EDA 9-2절에서 빈칸과 `Undoped`의 PCE 차이가 연도마다 부호가 바뀌었습니다. 또 Cl처럼 PCE가 낮은 첨가제와 다른 첨가제를 "있음" 하나로 묶었습니다.
3. **추천 근거가 얇습니다.** 3·4위는 사실상 논문 한 편(jacs.6b08347)의 값을 그대로 따라간 결과입니다. 데이터가 적은 구간에서 모델이 단일 논문에 끌려갑니다.
4. **연도 교란을 통제하지 않았습니다.** 최근 논문일수록 PCE가 높고 공정도 함께 바뀌었기 때문에, 추천 조건에 "최근 공정"이라는 효과가 섞여 있을 수 있습니다.
5. **정제가 덜 되었습니다.** LLM 추출 행, 실내광 측정(PCE 30% 이상 기록), 중복 행, PCE ≤ 0이 남아 있습니다.
6. **한 번의 분할로만 평가했습니다.** 교차검증을 하지 않아 점수의 편차를 알 수 없습니다.

이 한계들을 바탕으로 v2에서 바꿀 점은 [eda_report.md](eda_report.md) 7절, 9-5절, 9-6절에 정리되어 있습니다.
