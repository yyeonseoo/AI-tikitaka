# 전해질 전도도: 빠른 확인 (2026-10-22)

RAPID 연구 뒤에 "다른 깨끗한 데이터에서는 머신러닝이 단순한 식보다 나은가"를 보려고 짧게 확인한 결과입니다.

## 데이터

배터리 전해질 전도도 실험 5,035건 (Rahmanian et al., *Scientific Data* 2023, [Zenodo 10.5281/zenodo.7244939](https://doi.org/10.5281/zenodo.7244939), CC BY). 로봇이 용매 EC·PC·EMC와 리튬염 LiPF₆의 비율을 바꿔 전해질 504개를 만들고, −30~60°C에서 10°C 간격으로 전도도를 쟀습니다. 조성으로 묶으면 서로 다른 조성은 108개이고, 조성마다 4~5번씩 반복해서 만들었습니다.

받는 법: Zenodo에서 `Conductivtiy_experiment.csv`를 받아 `electrolyte/data/conductivity.csv`로 저장 (`data/`는 git 제외).

## 확인한 것

처음 보는 조성의 전도도를 맞힐 수 있나. 조성 단위로 5묶음으로 나눠, 한 묶음은 학습에서 빼고 맞혔습니다. 입력은 염 농도(몰랄), EC/(EC+PC), (EC+PC)/전체 용매, 온도이고, 예측 대상은 ln(전도도)입니다.

| 모델 | R² (ln σ) | 상대 오차 중앙값 |
|---|---|---|
| 아레니우스 식 (온도만, 조성 무시) | 0.822 | 18.9% |
| 2차 다항식 (조성 3개 + 1/온도) | 0.954 | 8.1% |
| 3차 다항식 | 0.962 | 6.2% |
| kNN (가까운 조성 5개 평균) | 0.949 | 8.5% |
| LightGBM | 0.962 | 6.4% |
| 재현 한계 (같은 조성·온도로 다시 만든 전해질의 평균으로 맞히기) | 0.967 | 5.6% |

## 결과

- 3차 다항식(식 하나)과 LightGBM의 성능이 같습니다(R² 0.962 대 0.962).
- 둘 다 이미 재현 한계(0.967)에 거의 닿아 있습니다. 같은 전해질을 다시 만들어도 이 정도 차이는 나기 때문에, 어떤 모델로도 더 좋아질 여지가 거의 없습니다.
- 변수가 4개뿐이고 관계가 매끄러워서, 이 데이터에서도 머신러닝이 단순한 식보다 나을 이유가 없습니다.

실행: `python electrolyte/quick_check.py` (몇 초)
