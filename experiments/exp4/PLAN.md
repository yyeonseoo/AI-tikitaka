# 실험 4 계획: 같은 입력·같은 기준으로 방법 재비교 (개발 데이터, 시간 순서 평가)

**작성일:** 2026-10-05. 실행 전에 커밋합니다.

**배경:** 외부 검토 2차에서 실험 1의 문제가 확인됐습니다. 튜닝 단계의 정답 노출, 부트스트랩 안 교차검증의 복사본 그룹, 서로 다른 입력 정보끼리의 비교입니다. 또 실험 1 설계에서는 정답이 아닌 후보가 학습 데이터에 남아 있어, 전체 후보 순위 지표가 부풀려집니다. 실험 4는 이 문제들이 구조적으로 생기지 않는 **시간 순서 평가**로 방법들을 다시 비교합니다.

**성격:** 2017년까지 데이터만 쓰는 **개발 단계 분석**입니다. 결과는 방법 선택과 다음 확인 평가의 계획에 쓰고, 최종 성능 주장에는 쓰지 않습니다.

## 질문

과거 논문으로 학습한 모델이 **다음 해 논문**에 보고된 공정 조합들의 효율 순서를, 같은 정보를 쓰는 단순한 방법보다 잘 맞히는가? 또 어떤 정보와 학습 방법이 도움이 되는가?

## 데이터

- **범위:** 정제 데이터 중 2017년까지만 씁니다. 2018년 이후는 읽지 않습니다(코드에서 assert로 확인).
- **정제:** 2026-10-05 수정판입니다. 광세기를 반영한 PCE 정합성 검사, 해석 불가 단계가 있는 어닐링 값은 결측 처리.
- **평가 연도 Y:** 2015, 2016, 2017. 각 Y에서 **학습 = Y년 이전의 모든 논문**, **평가 = Y년 논문**입니다. 2014년은 후보가 23개뿐이라 뺍니다.

## 후보와 정답

- **조합 정의:** 실험 1~3과 같습니다. 용매, DMSO 비율 구간, 반용매, 첨가제, 용매 어닐링, 어닐링 온도 10°C·시간 5분 단위.
- **후보:** 평가 연도의 조합 중 서로 다른 소자 3개 이상 + 서로 다른 논문 2편 이상.
- **조합의 실제 효율:**
  - **소자 평균 (주):** 조합 안 소자 PCE의 평균
  - **논문 평균 (보조):** 논문마다 평균을 낸 뒤 그 평균들을 다시 평균
- **정답:** 실제 효율 상위 10%입니다(정답 적중 지표에만 씀).

## 점수 매기기

- **입력:** 각 후보 조합의 평가 연도 실제 행을 씁니다. 연도는 학습 마지막 연도(Y−1)로, 측정 방식은 Reverse로 고정합니다(공통 함수). 소자 구성은 실제 값을 그대로 둡니다.
- **점수:** 행별 예측의 조합 평균입니다.

## 비교 방법

| 방법 | 입력 | 설정 선택 |
|---|---|---|
| LightGBM (전체) | 공정 7 + 소자 조건 5 + 보정 2 | 학습 연도 안 논문 단위 GroupKFold(5), MAE 기준. 후보 4개 × 결측 처리 2방식 |
| LightGBM (공정+보정) | 공정 7 + 보정 2 | 같음 |
| 선형 회귀 (전체) | 전체 14개 | alpha [0.1, 1, 10, 100]을 같은 방식으로 |
| 선형 회귀 (공정+보정) | 공정+보정 9개 | 같음 |
| 비슷한 조합 평균 (kNN) | 공정 변수 거리 | 학습 연도 조합 중 가장 가까운 5개의 평균 PCE. 같은 조합이 학습 연도에 있으면 포함(과거 기록). 거리 정규화는 학습 데이터 범위로 |
| LightGBM, 저효율 사례 제외 (전체) | 전체 | LightGBM(전체)에서 고른 설정, PCE < 5% 행 제외하고 학습 |
| LightGBM 10개 평균 (전체) | 전체 | 같은 설정, 학습 논문 단위 부트스트랩 10개의 조합 예측 평균 |
| LightGBM 10개 + 불확실성 보너스 (전체) | 전체 | 위 평균 + 1×모델 간 표준편차 (탐색용 점수, 확률 아님) |
| 무작위 | | 순위 일치도 0, 정답 적중 0.10, 효율 이득 0 (기대값) |

**설정 선택 기준에 대해:** 모델 설정은 MAE로 고릅니다. 평가 지표(순위 일치도)와 다른 기준이라는 한계를 결과와 함께 보고합니다.

## 지표

| 지표 | 내용 |
|---|---|
| **순위 일치도 (주)** | 모델 점수와 실제 소자 평균 효율의 Spearman 상관 |
| 순위 일치도 (논문 평균) | 실제 효율을 논문 평균으로 바꾼 것 |
| 정답 적중 | 실제 상위 10% 중 예측 상위 10%에 든 비율 |
| 효율 이득 (%p) | 예측 상위 10% 조합의 실제 효율 − 후보 전체 평균 |

## 불확실성

- **주 방식 (고정 후보):** 평가 연도의 논문을 복원 추출하는 논문 단위 부트스트랩을 연도마다 1,000회 돌립니다. **후보 목록은 원래 데이터 기준으로 고정**하고, 각 후보의 실제 효율만 다시 뽑힌 논문으로 다시 계산합니다. 재표집에 행이 없는 후보는 그 회에서 빼고 개수를 보고합니다. 모델은 학습 연도로 한 번 학습하고 고정합니다.
- **민감도 (후보 재선정):** 재표집마다 후보 자격을 다시 정합니다. 이때 소자 수는 원본 소자 기준으로 중복 없이 셉니다(복사본이 새 후보를 만들지 않게).
- **합치기:** 세 해의 결과는 같은 반복 번호끼리 평균해서 합칩니다. 연도별 결과도 따로 보고합니다.
- **보고:** 원래 데이터 점추정과 재표집 95% 구간을 함께 보고하고, 재표집 평균은 따로 표시합니다.

## 짝지은 비교 (미리 정함)

| 질문 | 비교 |
|---|---|
| 같은 공정 정보에서 비선형 모델이 필요한가 | LightGBM(공정+보정) − 선형 회귀(공정+보정) |
| 같은 공정 정보에서 모델이 비슷한 조합 평균보다 나은가 | LightGBM(공정+보정) − kNN |
| 소자 조건 정보가 도움이 되는가 | LightGBM(전체) − LightGBM(공정+보정), 선형 회귀(전체) − 선형 회귀(공정+보정) |
| 같은 전체 정보에서 비선형 모델이 필요한가 | LightGBM(전체) − 선형 회귀(전체) |
| 저효율 사례 제외가 도움이 되는가 | 저효율 제외 − LightGBM(전체) |
| 모델 10개 평균이 도움이 되는가 | 10개 평균 − LightGBM(전체) |
| 불확실성 보너스가 도움이 되는가 | 10개 + 보너스 − 10개 평균 |
| 실용 기준선 (정보량 다름) | LightGBM(전체) − kNN |

**판단 규칙:** 95% 구간이 0을 포함하면 "우열을 판단할 증거 부족"으로 씁니다.

## 보조 분석: 소자 구성을 고정한 상황 (추천 시점 흉내)

- **목적:** 사용자가 소자 구성(구조·ETL·HTL·후면전극)을 정하고 그 안에서 공정을 고르는 상황을 흉내 냅니다.
- **방법:** 평가 연도마다 소자 구성별로, 같은 구성 안의 공정 조합들만 후보로 놓습니다. 후보 조건은 그 구성 안에서 소자 3개 이상 + 논문 2편 이상입니다. 실제 효율도 그 구성의 소자로만 계산합니다.
- **대상:** 후보가 8개 이상인 (연도, 구성) 묶음만 씁니다. 각 묶음의 순위 일치도를 후보 수로 가중 평균하고, 같은 재표집 방식으로 구간을 냅니다.
- **성격:** 묶음 수가 적을 수 있어 탐색적 결과로만 보고합니다.
