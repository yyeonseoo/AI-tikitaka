# 실험 2 사전 계획 (결과를 보기 전에 확정·커밋)

**작성일:** 2026-10-03. 이 문서는 실험 2를 실행하기 전에 커밋합니다. 결과를 본 뒤 기준을 바꾸면 그 사실과 이유를 리포트에 따로 적습니다.

## 질문

2017년까지의 논문으로만 학습한 모델이, **학습 때 존재하지 않았던 2018~2019년 논문**에서 고효율 공정 조합을 무작위보다 잘 골라내는가?

## 데이터

| 구분 | 범위 | 규모 |
|---|---|---|
| 학습 | 2017년까지 **전부** (분할 파일의 train/test 구분 없이) | 8,127행 / 논문 1,688편 |
| 평가 | 2018~2019년 | 7,515행 / 논문 1,421편 |
| 사용 안 함 | 2020년 이후 | 303행 |

- **정제:** v2와 같습니다(LLM 추출·실내광·PCE ≤ 0·중복·물리적 불일치 제외).
- **하이퍼파라미터:** `models/v2/best_params_past.json`을 씁니다. 2017년까지 train 논문으로 고른 것이고, 실험 2용으로 다시 튜닝하지 않습니다.
- **노출 이력:** 2018~2019년 데이터는 v2 초기 개발 때 변수 선택(EDA)과 튜닝에 쓰인 적이 있습니다. 리포트에 한계로 명시합니다.

## 후보와 정답

- **조합 정의:** 실험 1과 같습니다. 용매, DMSO 비율 구간, 반용매, 첨가제, 용매 어닐링, 어닐링 온도 10°C·시간 5분 단위입니다.
- **후보:** 2018~2019년 데이터에서 소자 3개 이상 + 논문 2편 이상인 조합입니다. 사전 확인 결과 146개이고, 그중 2017년까지 데이터에 없던 새 조합은 45개입니다.
- **정답 (주):** 후보 중 **조합 안 소자 PCE 평균** 상위 10%입니다(사전 확인 15개).
- **정답 (보조):** 후보 중 **논문별 평균의 평균** 상위 10%입니다. 논문마다 평균을 먼저 내고, 그 평균들을 다시 평균합니다. 소자를 많이 낸 논문 한 편이 결과를 좌우하지 않게 하려는 것입니다.

## 점수 매기는 방법 (공통)

후보 조합의 2018~2019년 실제 행을 그대로 쓰되, 공통 함수 `candidate_inputs`로 **연도는 2017, 스캔 방향은 Reverse로 고정**합니다. 모델은 2017년 이후 연도를 학습한 적이 없기 때문입니다. 각 행을 예측한 뒤 조합별로 평균을 냅니다.

## 비교할 방법 (확정)

| 방법 | 입력 | 내용 |
|---|---|---|
| **LightGBM (주 방법, v2)** | 공정 + 소자 조건 + 보정 14개 | 과거 전용 하이퍼파라미터 |
| LightGBM, 실패 소자 제외 | 같음 | PCE 5% 미만 행을 빼고 학습 |
| LightGBM 10개 평균 | 같음 | 논문 단위 부트스트랩으로 학습한 LightGBM 10개. 조합 예측의 평균 |
| LightGBM 10개 + 불확실성 | 같음 | 위 10개의 평균 + 1×표준편차 |
| 선형 회귀 (Ridge) | 같음 | 원-핫 + 표준화, 결측은 중앙값 + 결측 표시. alpha는 2017년까지 데이터의 논문 단위 GroupKFold(5)로 [0.1, 1, 10, 100] 중 선택 |
| LightGBM, 공정만 | 공정 7 + 보정 2 | 소자 조건 없이 학습 |
| 선형 회귀, 공정만 | 공정 7 + 보정 2 | 위와 같음 |
| 비슷한 조합 평균 (kNN) | 공정 변수 거리만 | 2017년까지 데이터의 모든 조합 중 공정 거리가 가장 가까운 5개 조합의 평균 PCE. 범주 불일치 1, DMSO 구간·온도·시간은 0~1 정규화 차이. **후보와 같은 조합이 2017년까지 데이터에 있으면 포함**함. 과거에 실제로 해 본 레시피 기록이라 실험 2에서는 정당한 정보이기 때문 (실험 1에서는 같은 시기 숨김 설계라 제외했음) |
| 무작위 | | 기대값 0.10, 재표집마다 무작위 순열 1회 |

**제외:** 논문 안 순위 학습은 실험 1에서 v2보다 낮은 경우가 더 많아서 넣지 않습니다.

**동점 처리:** 조합별 고정 키로 정합니다.

## 지표

**주 지표:** "정답(상위 10%) 중 예측 상위 10% 후보 안에 든 비율"입니다. 무작위로 고르면 0.10입니다.

**보조 지표**
- 상위 20% 후보 안의 정답 비율
- 가장 좋은 정답의 순위 백분위
- 보조 정답 정의(논문 평균)에서의 주 지표

**소자 단위 지표 (2018~2019년 전체 행)**
- R², MAE, 순위 상관
- 고효율(PCE ≥ 15%) 판별의 ROC-AUC, PR-AUC, F1. F1 기준값은 2017년까지 데이터의 out-of-fold 예측에서 F1이 최대가 되는 값으로 정합니다.
- kNN은 조합 단위 방법이라 소자 단위 지표를 내지 않습니다.

**참고용:** 새 조합(2017년까지 없던 45개)만 따로 본 주 지표입니다. 정답 수가 적어 판정에는 쓰지 않습니다.

## 불확실성

- **방식:** 2018~2019년 **평가 논문**을 복원 추출하는 논문 단위 클러스터 부트스트랩을 1,000회 돌립니다.
- **재표집마다 다시 계산하는 것:** 후보 자격(서로 다른 원본 논문 2편 이상)과 정답을 그 재표집 안에서 다시 정합니다.
- **고정하는 것:** 모델은 2017년까지 데이터로 한 번만 학습하고 고정합니다. 학습 데이터 쪽 변동은 이 구간에 들어가지 않습니다.
- **비교 방식:** 모든 방법을 같은 재표집에서 계산해 짝지어 비교합니다.
- **시드:** 재표집 시드는 "기본 시드 + 반복 번호"이고, 재표집·앙상블·무작위 순열에는 서로 다른 난수 스트림을 씁니다.

## 판정 기준 (확정)

| 판정 | 기준 |
|---|---|
| **성공** | 주 방법(LightGBM)의 주 지표 95% 구간 하한이 0.10보다 높음 |
| 보강 근거 | 주 방법의 소자 단위 고효율 판별 ROC-AUC 95% 구간 하한이 0.5보다 높음 |
| 참고 | 새 조합만의 결과 (판정에 쓰지 않음) |
| 방법 비교 | (방법 − 주 방법)의 짝지은 차이. 95% 구간이 0을 포함하면 "우열을 판단할 증거 부족" |
| 주요 보조 비교 | kNN vs LightGBM, kNN vs LightGBM-공정만 |
| κ 효과 | LightGBM 10개 + 불확실성 − LightGBM 10개 평균 |

## 실행 전 점검

실제 실행 전에 코드가 제대로 도는지, **2017년까지 데이터 안에서 시험 실행**합니다. 2015년까지로 학습하고 2016~2017년으로 평가합니다. 2018년 이후 데이터는 본 실행에서 한 번만 씁니다.
