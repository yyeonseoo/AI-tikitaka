# 실험 3, 2단계 계획 (실행 전에 확정·커밋)

> **이 분석은 2018~2019년 데이터를 두 번째로 쓰는 사후 분석이다. 실험 2의 판정(사전 기준 미달)을 대체하지 않는다. 채점법은 2017년 이전 데이터 안의 연습(1단계)으로 정했다.**

**작성일:** 2026-10-04. 1단계 결과는 [reports/exp3_report.md](../../reports/exp3_report.md)에 있습니다.

## 질문

2017년까지 학습한 모델이 매긴 2018~2019년 공정 조합의 순위가, **예전에 해 본 비슷한 레시피의 평균(kNN)보다** 실제 효율 순위와 더 잘 맞는가?

## 데이터와 설정 (실험 2와 같음)

| 항목 | 내용 |
|---|---|
| 학습 | 2017년까지 전부: 8,127행 / 논문 1,688편 |
| 평가 | 2018~2019년: 7,515행 / 논문 1,421편 |
| 후보 조합 | 2018~2019년 조합 중 소자 3개 이상 + 서로 다른 논문 2편 이상. 원래 데이터 기준 146개, 그중 2017년까지 없던 새 조합 45개 |
| 조합의 실제 효율 | 조합 안 소자 PCE 평균 |
| 후보 입력 | 각 조합의 실제 2018~2019년 행. 연도는 2017, 측정 방식은 Reverse로 고정 (공통 함수 `candidate_inputs`) |
| 하이퍼파라미터 | `models/v2/best_params_past.json` (2017년까지 train 논문으로 선택). 다시 튜닝하지 않음 |
| 모델 | 2017년까지 데이터로 한 번만 학습하고 고정 |

## 비교 방법

| 방법 | 내용 |
|---|---|
| **LightGBM** | 공정 + 소자 조건 + 보정 14개 변수 |
| 선형 회귀 (Ridge) | 같은 14개 변수. alpha는 2017년까지 데이터의 논문 단위 GroupKFold(5)로 선택 |
| LightGBM, 공정만 | 공정 7 + 보정 2 변수 |
| **비슷한 조합 평균 (kNN)** | 2017년까지 데이터의 조합 중 공정 거리가 가장 가까운 5개 조합의 평균 PCE. 같은 조합이 2017년까지 있으면 포함 (실험 2와 같은 정의) |
| 무작위 | 순위 일치도 기대값 0, 추천 효율 기대값 = 후보 전체 평균 |

## 지표

- **순위 일치도:** 모델 점수(조합별 예측 평균)와 실제 조합 평균 효율의 Spearman 상관입니다. 동점은 평균 순위로 처리합니다.
- **추천 효율 이득 (%p):** (예측 상위 10% 조합의 실제 평균 효율) − (후보 전체의 평균 효율)입니다. 무작위 기대값은 0입니다. 상위 10% 안의 동점은 조합별 고정 키로 정합니다.

## 판정 기준 (확정)

| 구분 | 기준 |
|---|---|
| **주 기준** | **LightGBM − kNN** 순위 일치도 차이의 95% 구간 하한 > 0 (같은 재표집에서 짝지은 차이) |
| 보조 1 | LightGBM 순위 일치도의 95% 구간 하한 > 0 |
| 보조 2 | LightGBM 공정만 순위 일치도의 95% 구간 하한 > 0 |
| 보조 3 | 새 조합(2017년까지 없던 45개)만으로 계산한 LightGBM 순위 일치도와, LightGBM − kNN 차이. 평균과 95% 구간 보고 |
| 보조 4 | LightGBM의 추천 효율 이득(%p). 평균과 95% 구간 보고 |

- **보고 원칙:** 보조 기준은 모두 결과와 관계없이 보고합니다. 다른 방법(선형 회귀 등)의 같은 지표도 함께 보고합니다.
- **표현 규칙:** 95% 구간이 0을 포함하면 "우열을 판단할 증거 부족"이라고 쓰고, "차이 없음"이라고 쓰지 않습니다.

**판정 문구 (미리 정함):**
- **주 기준 충족:** "모델 순위가 비슷한 레시피 평균보다 실제 효율 순위와 더 잘 맞았다 (사후 분석)."
- **주 기준 미달 + 보조 1 충족:** "모델 순위는 무작위보다 실제와 맞지만, 비슷한 레시피 평균보다 낫다는 증거는 부족하다."
- **둘 다 미달:** "2018~2019년에서는 순위 신호를 확인하지 못했다."

## 불확실성

- **방식:** 실험 2와 같습니다. 2018~2019년 **평가 논문**을 복원 추출하는 논문 단위 부트스트랩을 1,000회 돌립니다. 재표집마다 후보 자격(서로 다른 원본 논문 2편 이상)을 다시 계산하고, 모델은 고정합니다.
- **같은 재표집:** 모든 방법을 같은 재표집에서 계산해 짝지어 비교합니다.
- **새 조합 부분:** 각 재표집 안에서 2017년까지 데이터에 없던 후보만 골라 같은 지표를 계산합니다. 새 후보가 10개 미만인 재표집은 그 부분에서만 빼고, 몇 번 빠졌는지 보고합니다.

**정의 보완 (사용자 지시에 없던 세부를 실행 전에 정함)**
1. **재표집 시드:** 실험 2와 같은 시드 방식을 써서 **실험 2와 같은 재표집 1,000개**를 만듭니다. 두 실험의 결과를 같은 재표집에서 나란히 볼 수 있습니다.
2. **무작위 기준값:** "추천 효율 이득"의 무작위 기준은 무작위 순열 1회가 아니라 **후보 전체 평균(기대값)**으로 합니다. 순열 1회는 그 자체로 잡음이 있기 때문입니다.
3. **판정 문구:** 위 "판정 문구"처럼 결과 조합별 문장을 실행 전에 정해 둡니다.
