# 실험 1·2·3 수정 재실행 계획 (실행 전에 확정·커밋)

**작성일:** 2026-10-05. 외부 검토 2차에서 확인된 문제를 고쳐 실험 1, 실험 2, 실험 3 2단계를 다시 실행합니다. 실험 3 1단계는 이미 수정판으로 실행했습니다([PLAN_phase1.md](exp3/PLAN_phase1.md)).

> **원래 결과와의 관계:** 원래 결과와 판정은 기록으로 남깁니다. 특히 **실험 2의 사전 판정(미달)은 그대로 유효합니다.** 실험 2·3의 수정 재실행은 2018~2019년 데이터를 세 번째로 쓰는 **사후 수정 분석**이고, 확인적 증거가 아닙니다.

## 모든 재실행에 공통으로 적용하는 수정

| # | 문제 | 수정 |
|---|---|---|
| 1 | 튜닝 단계의 평가 데이터 노출 | 하이퍼파라미터는 매번 **그 학습 데이터 안에서만** 고릅니다. 논문 단위 GroupKFold, MAE 기준. LightGBM은 후보 4개 × 결측 처리 2방식, 선형 회귀는 alpha 4개입니다. 재표집 안에서는 원본 논문 단위로 그룹을 나눕니다 |
| 2 | 부트스트랩 복사본이 교차검증 양쪽에 들어감 | 교차검증 그룹, 앙상블 내부 재표집, 후보 자격 계산을 모두 **원본 논문** 기준으로 합니다. 후보 자격의 소자 수는 원본 소자를 중복 없이 셉니다 |
| 3 | 입력 정보가 다른 방법끼리 비교 | 같은 정보끼리 짝지어 비교합니다(아래 방법표) |
| 4 | 정제 | 광세기를 반영한 PCE 정합성 검사, 해석 불가 단계가 있는 어닐링 값은 결측으로 처리합니다 |
| 5 | kNN 거리 정규화 | 학습 데이터 범위로만 합니다 |
| 6 | 보고 방식 | 원래 데이터 점추정과 재표집 95% 구간을 함께 쓰고, 재표집 평균은 따로 표시합니다. 소자 평균과 논문별 평균 두 기준을 모두 계산합니다 |
| 7 | 표현 | "저효율 사례", "공정+보정" 같은 이름으로 통일하고, 구간이 0을 포함하면 "우열을 판단할 증거 부족"으로 씁니다 |

## 방법 (모든 재실행에 같은 구성)

| 방법 | 입력 |
|---|---|
| LightGBM (전체) | 공정 7 + 소자 조건 5 + 보정 2 |
| LightGBM (공정+보정) | 공정 7 + 보정 2 (보정은 예측 때 고정) |
| 선형 회귀 (전체) / (공정+보정) | 위와 같음 |
| 비슷한 조합 평균 (kNN) | 공정 변수 거리, 가장 가까운 5개 |
| LightGBM 저효율 제외 (전체) | PCE < 5% 행 제외하고 학습 |
| LightGBM 10개 평균 / 10개 + 보너스 (전체) | 학습 논문 단위 부트스트랩 10개 |
| 무작위 | 기대값 |

**짝지은 비교:**
- 같은 공정 정보에서: LightGBM(공정+보정) − 선형 회귀(공정+보정), LightGBM(공정+보정) − kNN
- 정보 추가 효과: 전체 − 공정+보정 (LightGBM, 선형 회귀 각각)
- 같은 전체 정보에서: LightGBM(전체) − 선형 회귀(전체)
- 학습 방법 효과: 저효율 제외 − LightGBM(전체), 10개 평균 − LightGBM(전체), 10개 + 보너스 − 10개 평균
- 실용 기준선 (정보량 다름): LightGBM(전체) − kNN

## 실험 1 수정판: 같은 시기 안에서 숨긴 고효율 조합 찾기 (2017년까지)

- **문제:** 원래 설계는 정답 조합만 숨겨서, 정답이 아닌 후보가 학습 데이터에 남아 있었습니다. 그래서 후보 전체 순위 지표가 부풀려지고(학습한 조합을 다시 맞힘), 자기 자신을 빼고 계산하는 kNN과도 공정하지 않았습니다.
- **교차 채점으로 해결합니다.**
  1. 후보 조합을 실제 효율 순서대로 나열해 5묶음에 번갈아 배정합니다. 정답이 묶음마다 고르게 들어갑니다.
  2. 한 묶음씩 그 조합들을 숨기고 학습해서, 숨긴 묶음만 채점합니다.
  3. 모든 후보가 자기를 본 적 없는 모델로 채점됩니다. kNN도 학습 데이터에서 숨긴 묶음을 빼고 이웃을 찾습니다.
- **숨기는 방식 두 가지:**
  - (가) 묶음의 조합 행만 제외
  - (나) 묶음의 조합을 낸 논문의 모든 행 제외
- **정답:** 후보 중 실제 효율 상위 10%(소자 평균 기준, 논문 평균 기준 둘 다)
- **지표:** 순위 일치도(주), 정답 적중(상위 10% 안), 효율 이득(%p), 가장 좋은 정답의 순위 백분위
- **불확실성:** 2017년까지 논문을 복원 추출하는 논문 단위 부트스트랩입니다. 재표집마다 후보·정답·묶음을 다시 정하고 모든 모델을 다시 학습·튜닝합니다. 반복 횟수는 1회를 실제로 재고 정합니다(목표 100회. 병렬 실행 기준 전체 예상 시간이 12시간을 넘으면 50회). 원래 데이터 점추정도 보고합니다.
- **성격:** 개발 단계 분석입니다. 원래 실험 1의 수치(튜닝 노출, 부풀림 있음)를 대체합니다.

## 실험 2 수정판: 2017년까지 학습 → 2018~2019년 (사후 수정)

- **학습:** 2017년까지 전부. 튜닝은 그 안에서 논문 단위 GroupKFold(5)로 합니다(이전의 `best_params_past.json` 대신).
- **평가:** 2018~2019년 후보 조합. 소자 3개 이상(원본 소자) + 논문 2편 이상, 연도 2017·Reverse 고정.
- **주 지표 (원래 실험 2와 같음):** 정답(상위 10%) 중 추천 상위 10% 안에 든 비율. 무작위 = 0.10.
- **보조 지표:**
  - 순위 일치도, 효율 이득
  - 논문 평균 기준
  - 소자 단위 고효율(≥15%) 판별 AUC. 입력을 고정한 예측 기준이며, 원래 실험 2의 실제 입력 기준과 다르다는 점을 표시합니다.
- **불확실성:** 2018~2019년 논문 1,000회 재표집, 모델 고정. 원래 실험 2·3 2단계와 같이 **재표집마다 후보를 다시 정하는 방식이 주**이고, 원래 데이터 후보로 고정하는 방식은 민감도 분석입니다(실험 3 1단계는 고정 후보가 주).
- **판정 문구:** 원래 성공 기준(주 방법 하한 > 0.10)으로 결과를 적되, "사후 수정 재실행"임을 명시합니다.

## 실험 3 2단계 수정판: 2018~2019년 순위 일치도 (사후 수정)

- **학습·평가:** 실험 2 수정판과 같은 모델과 같은 재표집을 씁니다.
- **주 지표:** 순위 일치도 (소자 평균 기준)
- **비교:**
  - 원래 주 기준: LightGBM(전체) − kNN
  - **같은 정보 비교 추가:** LightGBM(공정+보정) − kNN, 선형 회귀(공정+보정) − kNN
  - 나머지는 위 짝지은 비교 전체
- **새 조합 분석:** 2017년까지 없던 조합만으로 순위 일치도를 따로 계산합니다(참고). 재표집에서 새 후보가 10개 미만이면 그 부분에서만 빼고 횟수를 보고합니다.
